如何在 Mac 上替影片自動上字幕

作者 Sky Lu發布於 2026年11月11日4 分鐘讀完

在 SkyCut 把影片放上時間軸，打開字幕面板，按生成字幕。SkyCut 會用 Apple 的語音辨識在你的 Mac 上把語音轉成文字，斷成好讀的短句，放到一條可以編輯的字幕軌上。你可以在同一台 Mac 上把這條軌翻譯成其他語言，然後把字幕燒進影片，或輸出成字幕檔。產生字幕需要 macOS 26，翻譯需要 macOS 15，SkyCut 只支援 Apple 晶片的 Mac。這些都包含在免費版裡；免費版輸出的影片帶有浮水印。

需要準備什麼

  • 一台 Apple 晶片的 Mac。從語音產生字幕需要 macOS 26；翻譯字幕需要 macOS 15 以上。
  • SkyCut，免費下載。手動產生、翻譯、輸出字幕不需要帳號。App 介面目前是英文、簡體中文和西班牙文，本文的按鈕名稱照簡體中文介面寫。
  • 影片中所說語言的語音模型。第一次使用時 macOS 會自動下載，那一次請保持連線。

四個步驟產生字幕

  1. 把影片放上時間軸

    建立專案，把影片拖進來。專案裡有配樂，或螢幕錄影自帶聲音都沒關係，第 3 步可以限定只轉寫哪些片段。

  2. 打開字幕面板

    按工具列上的字幕按鈕，它的提示文字是生成、翻译并编辑字幕轨。

  3. 選好設定

    在从音频生成底下，源语言（來源語言）可以維持自动检测（自動偵測），也可以自己選。每条字幕的行数預設是 1 行，也可以允許 2 行。只想轉寫人聲的話，先在時間軸上選取那些片段，再勾選只用选中的片段。

  4. 按「生成字幕」

    SkyCut 讀取音訊、轉寫、產生字幕。字幕會出現在一條字幕軌上，整個結果算一步復原。

產生出來的字幕長什麼樣子

SkyCut 不是把逐字稿原封不動貼到畫面上，而是依照影視字幕的慣例來排。

  • 句子在逗號這類自然停頓處斷開，太短的小句會併入相鄰的一句。
  • 每條字幕一行，除非你允許兩行；放不下的字會成為下一條。
  • 行尾的標點會去掉，句中的逗號換成空格；問號和引號保留。
  • 每條字幕留足閱讀的時間，前後不重疊。
  • 時間軸上被你隱藏的片段不會被轉寫。

語音辨識會出錯，多半錯在人名和專有名詞。在時間軸上點一條字幕就能改字和時間，也可以用编辑字幕…逐條檢查。

翻譯字幕

  1. 選語言

    在同一個面板的翻译底下，選目标语言（目標語言）。標示需要下載的語言，第一次使用時由 macOS 下載。

  2. 按「全部翻译」

    譯文會成為第二條字幕軌，原文還在，可以只顯示原文、只顯示譯文，或兩條都顯示。畫面上譯文預設疊在原文下方，拖曳其中一條之後就各自擺放。

  3. 保持同步

    改過原文之後，翻译缺失与过期的只會重新翻譯有更動的那幾句。

翻譯使用 Apple 翻譯，完全在你的 Mac 上進行。能翻哪些語言，取決於你這台 Mac 上 macOS 支援的語言組合。

輸出：燒進畫面，或輸出成檔案

你想要怎麼做得到什麼
字幕成為畫面的一部分在輸出面板勾選把字幕烧录进视频一個畫面上帶字幕的 MP4。隱藏中的字幕軌不會被燒進去。
給播放器或平台用的字幕檔在輸出面板使用导出字幕文件影片旁邊的 SRT 或 WebVTT 檔，檔名帶有語言。
只要字幕檔，不要影片只用导出字幕文件，不輸出影片單獨的字幕檔。

燒進去的字幕使用烧制字幕工具裡設定好的字體、大小、外框和位置，所以請先到那裡把樣式調好。

也可以交給 AI 助理

有 SkyCut Pro 的話，可以把整件事交給 Claude 或 Codex。先照用 Claude Code 剪片連接一次，接著直接說想要的結果。

替這個專案產生中文字幕，翻譯成英文，把兩種語言都輸出成 SRT 檔。

AI 助理用的是同一套本機辨識和翻譯，所以得到的字幕和你手動做的一樣。

要知道的限制

  • 產生字幕需要 macOS 26。在 macOS 15 上仍然可以匯入字幕檔、編輯、翻譯和輸出。
  • 能轉寫和翻譯哪些語言，以你這台 Mac 上 macOS 提供的為準。
  • 免費版輸出的影片帶有浮水印。字幕檔是一般檔案，沒有浮水印。
  • SkyCut 只支援 Mac：Apple 晶片，macOS 15 以上；沒有 Windows 版和 Intel 版。

常見問題

SkyCut 自動上字幕是免費的嗎？

是。手動產生、翻譯、編輯和輸出字幕都包含在免費版裡。免費版只有輸出的影片帶浮水印。

音訊會被上傳嗎？

不會。語音辨識和翻譯都在你的 Mac 上進行。第一次使用時 macOS 可能需要下載語言模型。

可以不輸出影片，只拿 SRT 檔嗎？

可以。輸出面板裡的导出字幕文件會單獨寫出字幕檔。

macOS 15 可以用嗎？

翻譯、編輯和輸出可以。從語音產生字幕需要 macOS 26。

畫面上可以同時顯示兩種語言嗎？

可以。先產生原文，再翻譯，讓兩條軌都顯示；燒錄時兩條都會畫上去。

在你的 Mac 上試試

SkyCut 免費下載。AI 剪輯屬於 Pro；第一次把 SkyCut 連上你的 Sky Studio 帳號時，會開始 7 天的 Pro 試用。
