Claude と Codex で使う動画編集 MCP サーバーの選び方

執筆 Sky Lu公開 2026年11月11日7 分で読めます

動画編集 MCP サーバーに「これが一番」という一つはありません。どれが合うかは、どこで編集するかで決まります。自分でも操作できる Mac ネイティブの編集ソフトの中で Claude や Codex に作業させたいなら、私たちが作っている SkyCut が合います。すでに DaVinci Resolve Studio で編集しているなら、コミュニティ製のサーバーが Resolve を操作します。画面収録から始まる作業なら、Tella が Mac、Windows、ウェブで使えるホスト型サーバーを提供しています。ファイルの一括処理だけなら、FFmpeg ベースのスキルで編集ソフトなしに済みます。下の表では 6 つの選択肢を、対応環境、サーバーが動く場所、自分で直せるタイムラインの有無で比べます。

動画編集 MCP サーバーとは

MCP（Model Context Protocol）は、AI アシスタントにツールを与える標準的な仕組みです。動画編集 MCP サーバーは、クリップの追加、トリミング、字幕の追加、書き出しといった編集ソフトの操作を、Claude や Codex が呼び出せるツールに変えます。アシスタントが編集を組み立て、編集ソフトが実行します。

実用上の違いは三つあります。どのコンピュータで動くか、素材が自分のマシンに残るか、そして結果が自分で開いて直せるタイムラインになるかどうかです。

選び方

  • Apple シリコンの Mac で、本格的な編集ソフトに AI を組み合わせたい。 SkyCut と Palmier Pro はどちらもローカルで動き、アシスタントを実際のタイムライン上で作業させます。SkyCut は macOS 15 以降、Palmier Pro は macOS 26 が必要です。
  • Windows や Intel Mac で使いたい。 ChatCut Desktop と DaVinci Resolve が対応しています。SkyCut は対応していません。
  • すでに DaVinci Resolve で編集している。 コミュニティ製サーバーは Resolve そのものを操作するので、プロジェクトはそのままです。外部スクリプトには有料の Studio 版が必要です。
  • 動画が画面収録中心。 Tella は画面収録と編集のツールで、サーバーは収録や公開も扱います。ホスト型なので、作業は Tella のサービスを通ります。
  • 変換、トリミング、字幕付けを一括でしたいだけ。 FFmpeg をまとめたスキルなら、ほかに何も入れずターミナルだけでできます。

決める前に確認したいこと

  • 素材の行き先。 ローカルのサーバーは自分のコンピュータで動き、ホスト型のサーバーはそのサービスが預かる素材を扱います。どちらの場合も、アプリ自体が何をアップロードするかを確認してください。ツールが返した内容はアシスタントに渡ります。
  • 自分で引き継げるか。 結果が編集ソフトのタイムラインなら、カット一つを手で直せます。書き出されたファイルだけなら、修正のたびに書き出し直しです。
  • 取り消しの仕組み。 アシスタントの変更が編集ソフトの通常の取り消し履歴に入るか、一連の作業をまとめて戻せるかを確かめます。
  • 実行前に何を確認してくるか。 ファイルの削除や有料の生成の前にアシスタントを止められる設定があるかを見ます。
  • 対応するアシスタント。 SkyCut、Palmier Pro、ChatCut、Tella はいずれも Claude と Codex の両方を挙げています。Resolve 用サーバーのインストーラは Claude Desktop、Claude Code、Codex CLI を設定できます。

SkyCut の場合

  • サーバーはローカルで、アプリに同梱されています。プロジェクトと素材は Mac に残ります。
  • ツール呼び出し 1 回が取り消し 1 回分で、Undo This Round を使えばアシスタントが作業を始める前の状態に戻せます。
  • Ask for approval にすると、既定の範囲を超える操作の前にアシスタントが止まります。有料の生成には、どのモードでも 1 日の上限がかかります。
  • Claude Desktop、Claude Code、Codex はボタン一つで接続できます。手順は Claude Code 編と Codex 編にあります。
  • AI 編集は SkyCut Pro（月額 $19 または年額 $149、米ドル）の機能で、SkyCut を Sky Studio アカウントに初めて接続したときに 7 日間の Pro トライアルが始まります。なお、アプリの表示言語は英語、簡体字中国語、スペイン語で、Windows 版と Intel 版はありません。

よくある質問

動画編集にはどの MCP サーバーがいいですか？

使っているコンピュータと編集ソフトによります。Apple シリコンの Mac なら、SkyCut と Palmier Pro がアシスタントにネイティブのタイムラインを与えます。Windows なら ChatCut Desktop か DaVinci Resolve、画面収録なら Tella が候補です。

Claude だけでなく Codex でも使えますか？

SkyCut、Palmier Pro、ChatCut、Tella は両方を挙げています。DaVinci Resolve 用のコミュニティ製サーバーも、Claude のほか Codex CLI 向けに設定できます。

素材は自分のコンピュータの外に出ますか？

SkyCut はプロジェクトと素材を Mac に残し、アシスタントにはフレームや文字起こしなどツールが返した内容だけを送ります。ほかのツールでは、ローカルのサーバーならアシスタントは自分のコンピュータ上の編集ソフトに届き、ホスト型ならそのサービスが預かる素材を扱います。アプリ自体が何をアップロードするかは各社の規約で確認してください。

Windows で使えるものはありますか？

あります。ChatCut Desktop、Tella、DaVinci Resolve は Windows で動きます。SkyCut が動くのは Apple シリコン搭載 Mac と macOS 15 以降だけです。

そもそも MCP サーバーは必要ですか？

ファイル処理だけなら不要です。Claude や Codex は FFmpeg を直接実行して、トリミング、結合、変換ができます。MCP サーバーが効くのは、タイムライン上で確認して直せる編集がほしいときです。

あなたの Mac で試す

SkyCut は無料でダウンロードできます。AI 編集は Pro の機能で、SkyCut を Sky Studio アカウントに初めて接続したときに 7 日間の Pro トライアルが始まります。
