Mac で Claude Code に動画編集を任せる方法

執筆 Sky Lu公開 2026年11月11日9 分で読めます

Claude Code は、操作できる編集ソフトがあれば動画を編集できます。Mac に SkyCut をインストールし、Sky Studio のキーを入力して、SkyCut の設定で Claude Code の横にある Connect を押します。すると Claude は SkyCut 内蔵のローカル MCP サーバーを通じて、本物のマルチトラックタイムライン上で作業します。素材を見て、話の間を詰め、タイトルや字幕を入れ、書き出すまでを行い、あなたは各変更をその場で確認し、調整や取り消しができます。SkyCut が動くのは Apple シリコン搭載 Mac と macOS 15 以降だけで、Windows 版と Intel 版はありません。

Claude Code が動画でできること、できないこと

Claude Code はターミナルで動く AI エージェントです。ファイルを読み、コマンドを実行できますが、動画を見ることも、音を聞くことも、クリップを並べることもできません。編集するには、それを代わりに行うツールが必要です。ツールは二種類あります。

  • コマンドラインツール。 Claude が FFmpeg のコマンドを書くか、それをまとめたスキルを実行します。トリミング、結合、変換といったファイル処理に向いています。変更のたびに新しいファイルを書き出し、自分で開いて直せるタイムラインはありません。
  • Claude が操作できる動画編集ソフト。 ソフトが MCP（Model Context Protocol。AI アシスタントにツールを与える標準的な仕組み）でタイムラインを公開します。Claude がそのツールを呼び出し、編集はすべてタイムラインに反映され、あなたが再生し、動かし、直せます。

SkyCut は後者で、MCP サーバーを内蔵した Mac ネイティブの動画編集ソフトです。以下ではこれを使います。

必要なもの

  • Apple シリコン（M1 以降）搭載の Mac と macOS 15 以降。無音カットや字幕生成など、音声を文字起こしする機能には macOS 26 が必要です。
  • SkyCut。ダウンロードは無料です。アプリの表示言語は英語、簡体字中国語、スペイン語で、日本語表示はありません。この記事のボタン名は英語表示のものです。
  • SkyCut Pro。AI 編集は Pro の機能です。SkyCut を Sky Studio アカウントに初めて接続したときに 7 日間の Pro トライアルが始まります（アカウントごとに 1 回、Mac ごとに 1 回）。
  • Claude Code。インストール済みで、自分の Claude プランでサインインしていること。SkyCut に AI の利用料は含まれません。

Claude Desktop と Codex も同じ画面から接続でき、使い方も同じです。ブラウザの通常の ChatGPT チャットは接続できません。SkyCut の MCP サーバーはあなたの Mac 上でローカルに動くためです。

5 ステップで設定する

  1. SkyCut をインストールする

    SkyCut をダウンロードし、ディスクイメージを開いて SkyCut を「アプリケーション」にドラッグします。セットアップガイド（英語）にこの手順の短い動画があります。

  2. Sky Studio のキーを入力する

    Sky Studio にサインインし、右上のアバターから SkyCut を選んでキーを作成します。SkyCut で Settings を開き、Sky Studio の欄にキーを貼り付けます。これで Pro が有効になり、トライアルが始まります。

  3. Claude Code を接続する

    SkyCut で Settings → Connect AI を開き、Claude Code の横の Connect を押します。SkyCut が claude mcp add を代わりに実行して自分の MCP サーバーを Claude Code に登録し、SkyCut のツールを許可するので、Claude がツールごとに確認で止まることはありません。

  4. Claude Code の新しいセッションを始める

    Claude Code はセッション開始時に MCP サーバーを読み込みます。新しいセッションを開いて /mcp と入力し、一覧に skycut があることを確認します。

  5. 素材の場所を Claude に伝える

    クリップが入っているフォルダと、作りたいものを Claude に伝えます。SkyCut がそのフォルダを開き、書き出しなどの新しいファイルもそこに保存されます。

最初の編集に使えるプロンプト

Claude には普通の言葉で頼めます。次のプロンプトはどれも SkyCut でできることに対応していて、同じプロジェクトに続けて実行できます。

SkyCut で ~/Movies/interview フォルダを開いて、全部のクリップを見て、それぞれの内容を教えて。

16:9 のプロジェクトを作って、良いテイク 3 本でラフカットを組んで。

トーク部分の長い間と「えー」「あの」などの言いよどみをカットして。

日本語の字幕を生成して、英語の翻訳を 2 本目のトラックに追加して。

冒頭 3 秒に「南極」というタイトルを入れて、1080p の MP4 で書き出して。

ほかにも、被写体に合わせたフレーミング、音楽のビートに合わせたカット、レイヤーとアニメーション、ナレーションの追加、完成した動画の問題点チェックができます。手順を細かく指示したくないときは、ドキュメンタリーや vlog といった編集スタイルを指定して、構成を任せることもできます。

Claude の作業を確認する

ここが本物の編集ソフトを使う理由です。Claude の作業中、SkyCut のツールバーには AI is editing と表示され、変更のたびにその場所へ移動します。いつでも Stop を押せます。

  • ツール呼び出し 1 回が取り消し 1 回分なので、⌘Z で Claude の編集を一つずつ戻せます。
  • Claude の作業が終わったら、Undo This Round でそのラウンドが始まる前の状態にプロジェクトを戻せます。
  • 何もロックされません。クリップをドラッグし、字幕のタイミングを直し、タイトルを書き換えてから、続きを Claude に頼めます。
  • SkyCut には権限モードが二つあります。Ask for approval は、ファイルの削除など既定の範囲を超える操作の前に止まって確認します。Full access はそのまま実行し、何をしたかを報告します。有料の生成にかかる 1 日の上限はどちらのモードでも有効です。

始める前に知っておきたい制限

  • Mac 専用です。Apple シリコンと macOS 15 以降が必要で、Windows と Intel Mac では動きません。
  • Claude はあなたのように動画を「見る」わけではありません。SkyCut のツールでフレームを抜き出し、音量を調べ、文字起こしを読みます。公開前に必ず自分で確認してください。
  • プロジェクトと素材はあなたの Mac に残ります。ただし、フレームや文字起こしなどツールが返す内容は、会話の一部として Claude に送られます。

Claude で動画編集するほかの方法

SkyCut が唯一の方法ではありません。どれが合うかは作業の内容によります。

  • FFmpeg ベースのスキル。 FFmpeg と Whisper をまとめたオープンソースの Claude Code スキルがあり、ターミナルで動きます。ファイルの一括処理に向いていて、編集ソフトは不要です。確認できるタイムラインはありません。
  • ほかの編集ソフト向けの MCP サーバー。 DaVinci Resolve をスクリプト API 経由で操作するコミュニティのプロジェクトがあります。macOS、Windows、Linux で動き、外部スクリプトには有料の Studio 版が必要です。

Mac を使っていて、自分の手でも操作できる編集ソフトの中で Claude に作業させたいなら、SkyCut が合います。

よくある質問

Claude Code だけで動画編集はできますか？

できません。Claude Code が扱うのはテキストとコマンドです。動画を変更するには、FFmpeg か、SkyCut のように Claude が操作できる編集ソフトが必要です。

Claude Desktop や Codex でも使えますか？

使えます。SkyCut の Settings → Connect AI に、Claude Desktop、Claude Code、Codex それぞれの Connect ボタンがあります。ローカルの stdio MCP サーバーに対応したクライアントなら、ほかのものでも使えます。

無料ですか？

SkyCut のダウンロードと手動編集は無料です。Claude に編集させるには SkyCut Pro が必要で、7 日間のトライアル終了後は月額 $19 または年額 $149（米ドル）です。別途、自分の Claude プランも必要です。

Windows で使えますか？

使えません。SkyCut は Apple シリコン搭載 Mac と macOS 15 以降でのみ動きます。

素材はアップロードされますか？

編集はあなたの Mac 上で行われ、プロジェクトもそこに残ります。Claude には、フレームや文字起こしなど、依頼に応じてツールが返した内容が送られます。

あなたの Mac で試す

SkyCut は無料でダウンロードできます。AI 編集は Pro の機能で、SkyCut を Sky Studio アカウントに初めて接続したときに 7 日間の Pro トライアルが始まります。

Mac 版をダウンロードセットアップガイドを読む
