Mac で Codex に動画編集を任せるやり方

執筆 Sky Lu公開 2026年11月11日8 分で読めます

Codex は動画を編集できますが、単体ではできません。操作できる動画編集ソフトが必要です。Mac に SkyCut をインストールし、Sky Studio のキーを入力して、Settings → Connect AI で Codex の横にある Connect を押します。SkyCut が自分のローカル MCP サーバーを Codex の設定に追加し、以後 Codex は素材を開き、タイムラインを組んでトリミングし、タイトルと字幕を入れ、書き出せるようになります。変更はすべて編集ソフト上で確認でき、取り消しもできます。SkyCut が動くのは Apple シリコン搭載 Mac と macOS 15 以降だけで、Windows 版と Intel 版はありません。

Codex で動画編集はできる？

Codex はコーディング用のエージェントです。ファイルを読み、コマンドを実行しますが、自分で動画を見たりクリップを並べたりはできません。動画を扱わせる方法は二つあります。

  • スクリプトとコマンドラインツール。 Codex が FFmpeg のコマンドを書きます。トリミング、結合、変換といったファイル処理には使えますが、変更のたびに新しいファイルを書き出し、確認できるタイムラインはありません。
  • MCP で操作できる編集ソフト。 編集ソフトがタイムラインをツールとして公開し、Codex がそれを呼び出します。編集はタイムラインに反映され、再生も手作業での修正もできます。

SkyCut は MCP サーバーを内蔵した Mac ネイティブの動画編集ソフトなので、この記事では後者の方法を使います。同じ設定は Claude でも使えます（Claude Code 編）。

必要なもの

  • Apple シリコン搭載の Mac と macOS 15 以降。無音カットや字幕生成など、音声を文字起こしする機能には macOS 26 が必要です。
  • SkyCut。ダウンロードは無料です。アプリの表示言語は英語、簡体字中国語、スペイン語で、日本語表示はありません。
  • SkyCut Pro。AI 編集は Pro の機能です。SkyCut を Sky Studio アカウントに初めて接続したときに 7 日間の Pro トライアルが始まります（アカウントごとに 1 回、Mac ごとに 1 回）。
  • Codex。自分の ChatGPT プランでサインインした Codex CLI、IDE 拡張機能、または ChatGPT デスクトップアプリ。SkyCut に AI の利用料は含まれません。

ブラウザの通常の ChatGPT チャットは接続できません。SkyCut の MCP サーバーはあなたの Mac 上でローカルに動き、同じ Mac 上のクライアントからしか届きません。

4 ステップで Codex を接続する

  1. SkyCut をインストールする

    SkyCut をダウンロードし、ディスクイメージを開いて SkyCut を「アプリケーション」にドラッグします。セットアップガイド（英語）にこの手順の短い動画があります。

  2. Sky Studio のキーを入力する

    Sky Studio にサインインし、右上のアバターから SkyCut を選んでキーを作成します。SkyCut で Settings を開き、Sky Studio の欄にキーを貼り付けます。これで Pro が有効になり、トライアルが始まります。

  3. Codex を接続する

    Settings → Connect AI を開き、Codex の横の Connect を押します。SkyCut は ~/.codex/config.toml のバックアップを保存してから [mcp_servers.skycut] の表を追加し、SkyCut のツールを許可するので、Codex が呼び出しのたびに承認を求めることはありません。Codex CLI、IDE 拡張機能、デスクトップアプリはこのファイルを共有しているので、三つすべてから SkyCut が見えます。

  4. Codex の新しいセッションを始める

    新しいセッションで /mcp と入力するか、ターミナルで codex mcp list を実行します。一覧に skycut があれば準備完了です。あとはクリップが入っているフォルダを Codex に伝えます。

最初の編集に使えるプロンプト

ほしい結果を普通の言葉で伝えます。どれも SkyCut でできることに対応しています。

SkyCut で ~/Movies/demo フォルダを開いて、それぞれのクリップの内容を教えて。

画面収録 2 本から、SNS 用の 60 秒の縦型動画を作って。機能を説明している部分は残して。

音声トラックの間と言いよどみをカットして、そのあと字幕を生成して。

冒頭 3 秒にタイトルを入れて、同じフォルダに 1080p の MP4 で書き出して。

Codex はフレームを 1 枚ずつ見る、音量を調べる、字幕を読む、書き出した動画を点検する、といったこともできます。あなたが見る前に自分の作業を確認させることができます。

実際に計測した結果

2026 年 10 月に自分たちで試しました。Codex CLI を SkyCut に接続し、小型で高速なモデルを低い推論設定で使っています。12 回のツール呼び出しで、フォルダとプロジェクトを開き、フレームを 1 枚見て、音を 10 秒聞き、字幕を読み、タイトルを追加し、480p の下書きを書き出して、結果を確認しました。所要時間は約 60 秒で、Codex がツールの承認で止まることは一度もありませんでした。

このテストで確かめたのは、接続から書き出しまで通るかどうかだけです。仕上がりの良し悪しは、選ぶモデルと、指示の具体さで変わります。

確認と取り消し

  • Codex の作業中、SkyCut のツールバーに AI is editing と表示され、変更のたびにその場所へ移動します。Stop で止められます。
  • ツール呼び出し 1 回が取り消し 1 回分です。Undo This Round で、そのラウンドが始まる前の状態に戻せます。
  • いつでも手作業で編集でき、その続きを Codex に頼めます。

始める前に知っておきたい制限

  • Mac 専用です。Apple シリコンと macOS 15 以降が必要で、Windows と Intel Mac では動きません。
  • Codex は SkyCut のツールでフレームを抜き出し、文字起こしを読みます。動画を通して見ているわけではないので、仕上がりは自分で確認してください。
  • プロジェクトと素材はあなたの Mac に残ります。フレームや文字起こしなどツールが返す内容は、会話の一部として Codex に送られます。

よくある質問

Codex で動画編集はできますか？

できます。ただし操作できる編集ソフトが必要です。SkyCut を接続すると、Codex はあなたの Mac 上の本物のタイムラインで編集します。単体では、ファイルに対して FFmpeg などのコマンドラインツールを実行することしかできません。

ブラウザの ChatGPT でも使えますか？

使えません。MCP サーバーは Mac のローカルで動くため、その Mac 上の Codex（CLI、IDE 拡張機能、デスクトップアプリ）が必要です。

Codex と Claude Code、どちらを使うべきですか？

どちらも同じ画面から接続し、同じ SkyCut のツールを使います。すでに契約しているほうで構いません。両者の品質比較は公開していません。

無料ですか？

SkyCut のダウンロードと手動編集は無料です。Codex に編集させるには SkyCut Pro が必要で、7 日間のトライアル終了後は月額 $19 または年額 $149（米ドル）です。別途、自分の ChatGPT プランも必要です。

Windows で使えますか？

使えません。SkyCut は Apple シリコン搭載 Mac と macOS 15 以降でのみ動きます。

あなたの Mac で試す

SkyCut は無料でダウンロードできます。AI 編集は Pro の機能で、SkyCut を Sky Studio アカウントに初めて接続したときに 7 日間の Pro トライアルが始まります。
