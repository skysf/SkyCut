Mac で動画に字幕を自動で付ける方法

執筆 Sky Lu公開 2026年11月11日6 分で読めます

SkyCut で動画をタイムラインに置き、字幕パネルを開いて Generate Subtitles を押します。SkyCut は Apple の音声認識を使って Mac 上で音声を文字起こしし、読みやすい短い行に分けて、編集できる字幕トラックに並べます。そのトラックは同じ Mac 上で別の言語に翻訳でき、字幕を動画に焼き込むことも、字幕ファイルとして書き出すこともできます。字幕の生成には macOS 26、翻訳には macOS 15 が必要で、SkyCut が動くのは Apple シリコン搭載 Mac だけです。ここまですべて無料プランに含まれます。無料プランで書き出した動画には透かしが入ります。

必要なもの

  • Apple シリコン搭載の Mac。音声からの字幕生成には macOS 26、字幕の翻訳には macOS 15 以降が必要です。
  • SkyCut。ダウンロードは無料で、手作業での字幕の生成、翻訳、書き出しにアカウントは要りません。アプリの表示言語は英語、簡体字中国語、スペイン語で、この記事のボタン名は英語表示のものです。
  • 動画で話されている言語の音声モデル。初回は macOS が自動でダウンロードするので、そのときはオンラインにしておきます。

4 ステップで字幕を生成する

  1. 動画をタイムラインに置く

    プロジェクトを作って動画をドラッグします。BGM や、音声付きの画面収録が入っていても構いません。どのクリップを文字起こしするかは手順 3 で絞れます。

  2. 字幕パネルを開く

    ツールバーの字幕ボタンを押します。ヒントには Generate, translate, and edit subtitle tracks と表示されます。

  3. 設定を選ぶ

    Generate from audio の Source language は Auto-detect のままでも、自分で言語を選んでも構いません。Lines per subtitle は既定で 1 line、2 lines も選べます。声だけを文字起こししたいときは、先にタイムラインでそのクリップを選択し、Only the selected clips にチェックを入れます。

  4. Generate Subtitles を押す

    SkyCut が音声を読み込み、文字起こしして、字幕を組み立てます。字幕は字幕トラックに並び、全体が取り消し 1 回分になります。

生成される字幕の体裁

SkyCut は文字起こしをそのまま画面に貼るのではなく、放送字幕の慣習に沿って整えます。

  • 文は読点などの自然な切れ目で分け、短すぎる部分は隣とまとめます。
  • 2 行を許可しないかぎり、字幕は 1 行ずつです。入りきらない文字は次の字幕になります。
  • 行末の句読点は省き、行の途中の読点は空白に置き換えます。疑問符と引用符は残します。
  • 各字幕は読める長さだけ表示され、前後が重なりません。
  • タイムラインで非表示にしたクリップは文字起こしされません。

音声認識は間違えます。多いのは人名や専門用語です。タイムラインで字幕をクリックすれば文言とタイミングを直せます。Edit Subtitles… で一覧として順に確認することもできます。

字幕を翻訳する

  1. 言語を選ぶ

    同じパネルの Translate で Target language を選びます。ダウンロードが必要と表示された言語は、初回に macOS が取得します。

  2. Translate All を押す

    翻訳は 2 本目の字幕トラックになります。原文は残るので、原文だけ、翻訳だけ、両方、のどれでも表示できます。画面上では、どちらかをドラッグするまで翻訳は原文の下に重なって表示されます。

  3. ずれを直す

    原文を編集したあとは、Translate Missing & Stale で変更のあった行だけを翻訳し直せます。

翻訳は Apple の翻訳機能を使い、すべてあなたの Mac 上で行われます。使える言語の組み合わせは、その Mac の macOS が対応しているものです。

書き出し：焼き込むか、ファイルにするか

ほしいもの操作結果
映像の一部になった字幕書き出しパネルで Burn subtitles into the video にチェック字幕が描き込まれた MP4 が 1 本。非表示の字幕トラックは焼き込まれません。
プレーヤーや配信先に渡す字幕ファイル書き出しパネルで Export Subtitle Files を使う動画の隣に、言語名付きの SRT または WebVTT ファイル。
字幕ファイルだけ（動画は不要）動画は書き出さずに Export Subtitle Files だけを使う字幕ファイルのみ。

焼き込む字幕のフォント、サイズ、縁取り、位置は Burn In Subtitles ツールで設定したスタイルが使われるので、先にそこで見た目を整えます。

AI アシスタントに任せることもできる

SkyCut Pro なら、作業全体を Claude や Codex に任せられます。Claude Code 編の手順で一度接続しておき、ほしい結果を伝えます。

このプロジェクトの日本語字幕を生成して、英語に翻訳して、両方を SRT ファイルで書き出して。

アシスタントも同じ Mac 上の認識と翻訳を使うので、手作業と同じ字幕が得られます。

知っておきたい制限

  • 字幕の生成には macOS 26 が必要です。macOS 15 でも、字幕ファイルの読み込み、編集、翻訳、書き出しはできます。
  • 文字起こしと翻訳ができる言語は、その Mac の macOS が提供しているものです。
  • 無料プランで書き出した動画には透かしが入ります。字幕ファイルはただのファイルなので透かしはありません。
  • SkyCut は Mac 専用です。Apple シリコンと macOS 15 以降が必要で、Windows 版と Intel 版はありません。

よくある質問

SkyCut の字幕自動生成は無料ですか？

無料です。手作業での字幕の生成、翻訳、編集、書き出しは無料プランに含まれます。無料プランでは、書き出した動画にだけ透かしが入ります。

音声はどこかにアップロードされますか？

されません。音声認識も翻訳もあなたの Mac 上で動きます。初回は macOS が言語モデルをダウンロードすることがあります。

動画を書き出さずに SRT ファイルだけ取り出せますか？

できます。書き出しパネルの Export Subtitle Files で字幕ファイルだけを書き出せます。

macOS 15 で使えますか？

翻訳、編集、書き出しは使えます。音声からの字幕生成には macOS 26 が必要です。

2 つの言語を同時に表示できますか？

できます。原文を生成して翻訳し、両方のトラックを表示します。焼き込むと両方が描かれます。

あなたの Mac で試す

SkyCut は無料でダウンロードできます。AI 編集は Pro の機能で、SkyCut を Sky Studio アカウントに初めて接続したときに 7 日間の Pro トライアルが始まります。
