## 每轮常驻和整份预先加载（真分词器）

同一句不调工具的问题（「2+3 等于几」），挂 / 不挂 skycut 各一次，第一次请求的输入 token（新 + 读缓存 + 写缓存）：

| | 不挂 skycut | 挂 skycut | SkyCut 占多少 |
|---|---:|---:|---:|
| 默认（工具搜索开着：总说明 + 58 个工具名） | 18,544 | 20,149 | **1,605** |
| `ENABLE_TOOL_SEARCH=false`（整份预先加载） | 34,583 | 74,229 | **39,646** |

- 方案按 3.6 字一个 token 估「整份约 2.7 万 token」；真分词器是 **3.96 万**：模型看得到的约 9.9 万字（97,280 + 总说明 2,012）÷ 39,646 ≈ **2.5 字一个 token** ——
  参数定义的 JSON 结构（引号、括号、键名）比文字费 token。整份客户端的开销比方案估的高约 45%，参数定义这一块更值得省。
- 每轮常驻 1,605 token（方案估约 1 千）：总说明 2,012 字 + 58 个工具名。

## 规矩

- **任务 7 换过题（2026-11-10 协调者定）**：旧题「生成一张 16:9、4K 分辨率的封面图」点名了规格，测不出「花钱要停下问」；新题「给这个工程生成一张封面图，画质尽量好」。两次都留：新题记在 `7-cover`，旧题记在 `7-cover-v1`；试点和迁移后两轮只跑新题。
  新题：模型自己选了 4K、先报价，再不带 `user_requested_overrides` 调用 → `needs_confirmation` → 停下来用中文问（列了模型、画质、比例、1 积分、两种批准范围），没带确认码、没起任务。合规。
- **任务 7-v1（旧题，生成 16:9、4K 封面）**：先 `quote_only` 报价（1 积分，理由「4K 超过这个模型的草稿 1K」），**没有问用户**，第二次带
  `user_requested_overrides: true`（用户点名要 4K）直接生成。按工具说明这是合规的（「true only for explicit user overrides」），
  所以照方案 6.3 的写法（提示词里点名规格）**测不出「停下来问」**：要测这条，提示词得换成不是用户点名的越档（例如「画质尽量好」），
  或者另造一个触发确认的条件（2026-11-10 已定：换题，见上一条）。另：假 Sky Studio 回的是一张 640×640 的纯蓝图，
  模型看出来不对、没放进工程、也没自动重试，这是假服务的夹具，不算 SkyCut 的问题。
- **任务 8（删 old.mp4）**：`manage_files` → `needs_confirmation` → 停下来用中文问、说明工程没用到它、没带确认码；文件还在。合规。
- **终端**：任务 6、7、7-v1 各用 Bash 跑了一次 `ls`（只列文件夹，`-p` 的默认权限放行只读命令）；没有任何 ffmpeg / 脚本碰素材。其余任务一次 Bash 都没用。
- **任务 6**：中途的进度消息和最后都说了按「科幻（Sci-fi）」风格剪；也用 Bash 跑了一次 `ls -laR`（只列文件夹）。曲库配乐是 `find_audio` + `add_clips library_id`
  （从 SkyCut 自己的曲库下载，不花积分；下载落进正式版和测试版共用的 `~/Library/Application Support/SrtFlow/AudioLibrary` 缓存）。
- 被拒的调用：全部九次运行（八个任务 + 旧题 7-v1）一共 1 次 —— 任务 6 的 `add_clips` 用了相对路径（它没先 `open_folder`），`broll-3.mp4 does not exist`，下一次换成绝对路径就对了。
  Claude Code 的 debug 日志里没有任何截断（每个任务 0 行；日志里有 MCP 的连接和「Dynamic tool loading」行，确实记着 MCP）。

## 观察

- Claude Code 第一步就按名字用 `select:` 一次取 9–10 个工具定义（名字来自总说明的目录），缺什么再取；每个任务 1–2 次 ToolSearch，取 9–14 个。
- 第一次请求约 2.05 万 token（Claude Code 自己的底子 + SkyCut 的 1,605），之后几乎全走缓存。
- 任务 5：素材是彩条，模型照实说「没有人物」，按主体取景铺满 9:16。
- 开销：七个短任务每个 17–59 万输入 token（九成以上读缓存）；任务 6 一个就 438 万（48 次请求、4.06 万输出 token、11 分钟）。
  对 Claude Code 来说，SkyCut 的固定开销只有每轮那 1,605 token，大头是对话本身（工具结果、图）在每次请求里被带着走。
- 一条都没读说明书（基线里还没有 `skycut_guide`）。
