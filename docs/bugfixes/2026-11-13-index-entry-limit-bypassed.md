## 根因

1. **守卫按一种物理前缀认「一条」，Markdown 的一条是逻辑上的。** `index($0, "- [") == 1` 只看顶格 `- [` 开头的那一行；
   可 Markdown 里 `+`、`*`、`1.` 照样是列表，缩进的行、紧跟着的不缩进的行都是上一条的续行，表格行也能当索引写。摘要换一种合法写法就长回来，
   每一行都不归守卫管。它量的是「有没有一行太长」，不是「一条一共多长」。
2. **收成一句话时按「主要意思」概括，限定被当成细节删了。** 带「只有」的句子留下绝对的主干，括号里的例外换成省略号；实测数字被从它的条件
   （客户端、构建、缓存）里拿出来拼成一句；只在一个入口生效的修法被写成泛指。旧摘要里这些限定都在，收短时一起删了。
   D1 当时的验证是「每一行的链接集合都在、规矩都在正文里」—— 这只证明文档找得到，证明不了一句话没说反。
3. **必读表的左列被当成摘要一起收了**，可它是检索线索：左列是别人按类型名、参数名搜到这一行的入口。

## 教训 / 防回归

1. **守卫要按被守的格式自己的规矩认「一条」。** Markdown 的一条是逻辑上的（列表记号、缩进、续行、表格行），按一种物理前缀数只拦得住老老实实的写法。
   写完拿「换一种合法写法」去打它，改之前的守卫绿、改之后的红才算数；只打「把那一行写长」这一种，验证的是守卫已经会的东西。
2. **收短文档时，「只有 / 一律」的例外、实测数字的条件、修法的适用范围都是规矩的一部分，不是细节。** 清单在
   [文档索引怎么写](../architecture/doc-indexes.md)第三节：例外写全或只写话题、数字带着条件、修法写明入口、左列的检索词别删、拿不准就照抄正文。
3. **「链接都还在」只证明找得到，证明不了没说反。** 收短之后要对着正文逐条读那一句话。
4. **不设上限的地方要写明是有意的、为什么**（必读表、检查入口），不然下一个人以为漏了，或者以为那里可以塞摘要。

## 后续（同日）：Codex 又跑出 4 类，守卫改成白名单；案例索引改按日期后面那一段排

上面两轮之后，Codex 把这条守卫又审了一遍（实跑 74 个场景），找出 4 类照样退出 0、或者报错报错了对象的写法：

- **链接只认 `(xxx.md)` 这一种**：带 `#锚点` 的死链、引用式链接（`[字][名]` 加 `[名]: 路径`）、`<a href>` 里的死链都不查；HTML 注释和代码围栏里的路径
  却算作「有索引」；唯一的索引带 `#锚点` 时反而说它「没索引」；带括号、空格的文件名认不出。
- **表格里的条目不查顺序和重复**；`./case.md` 和 `case.md` 当成两份。
- **行首一个 `|` 就算表格行**，不用表头和分隔行：三行各 380 字节的摘要这样塞回来，退出 0；指路小节里用 `>` 引用写的案例条目不拦。
- **算上限的 `find` 带了 `-type f`，查漏索引的两处没带**：叫 `xxx.md` 的目录被说成「没索引」，照提示补了链接又成死链。

**根因**（就是上面的根因 1，只是又深了一层）：守卫是「认出不许的写法才红」。Markdown 里合法的写法比守卫列得出来的多，列一种补一种，补了三轮还有。
而且同一件东西提取了好几次、每次口径不一样：漏索引和死链用一个正则、顺序和重复只认一种前缀、上限和漏索引各用一个 `find`。

**教训**：

1. **守一种格式，要么写白名单，要么把那种格式的全部写法认全。** 「认出不许的才红」在合法写法比你想得到的多的格式上守不住：三轮是同一个根因。
   白名单的代价是偶尔拦住一种无害的写法，那时改一下写法就行；黑名单漏掉的要等下一个人来试才知道。
2. **同一件东西只提取一次，几道检查用同一份。** 漏索引、死链、顺序、上限各认各的，认得出的集合不一样，缝就在它们之间。
3. **负例要留在仓库里跟着守卫跑。** 前两轮的探针都在仓库外，第三轮没人能先跑一遍；想到一种新的绕法，先写成场景、再改守卫。
4. **报错说错了对象也是 bug**（把目录说成没索引的文档、把带锚点的索引说成没索引）：照着提示改不好。

**收口核查（同日，Codex 回头核 #424）**：白名单还漏两处 —— 套在引用、列表里的 `~~~` 围栏不拦（只认行首的），里面唯一的路径照样算索引（D6R-12）；
链接的文字只有细空格、盲文空白这类 Unicode 空白也算「有文字」（D6R-14）。改成两份文件里出现 `~~~` 就红（和连着的反引号一样不看位置），
链接的文字正着认：至少一个字母、数字或汉字（行内代码里的也算），不再往黑名单里补空白。Codex 的 6 个输入在整份副本上改之前都退出 0、改之后红在插进去的那一行，
也进了自测（202 个场景）；撤掉任一处修复，对应的场景就红。往后这条守卫只防照规矩写的人无心写错，故意构造的写法记进「拦不住的」、不再一种一种补
（[文档索引怎么写](../architecture/doc-indexes.md)第六节最后）。
