# 2026-11-01 AI 权限模式、低成本草稿和日预算硬上限

## 症状

Codex 角色/巴黎试片默认使用 Nano2 2K、H3 2K，130 积分视频再以 1080p 交付；原每日额度可通过一次性确认继续超支。用户需要两种权限模式、代理代改必须先询问，以及中文对话用「请求批准 / 全部权限」。

## 根因

目录图片默认与客户端直接照抄均偏向 2K；standard 只约束模型偏好，未约束分辨率。收费闸只判断每日软阈值；设置工具没有权限模式，也没有敏感设置的确认步骤。

## 修复

增加 AIAccessMode/Store 与原生设置行，MCP 复用同 Store。权限变更在全部权限下也先发绑定整批参数的确认令牌；提高硬预算同样确认。AIDraftPolicy 按目录挑最低图片 / 720p 级视频；生成前比较规格与兼容首选模型的精确草稿报价。请求批准支持单次 / 本项目同规格和价格上限；全部权限执行并通知。每日预算在生成、配音、替换和手动 upscale 入口均为硬上限，超额提供设置入口；余额不足保留充值字段。增加只报价、不生成的预检。通知说明源片/画布/导出是不同规格，不能以高分源片冒充低分成片。

## 验证

无真实积分：全量 check-all 76 项通过；最终候选的 Sky Studio 检查 831 项、MCP 检查 2687 项通过，并完成独立 App 假服务设置冒烟。原生 App 已完整编译；Sky Studio 纯值/假服务检查 831 项通过。反向验证临时恢复 Nano2 旧 2K 默认并让全部权限跳过权限变更确认，必须分别触发对应回归，再恢复修复。独立 App 的 settings.py / permissions.py / zero.py 已通过：实际 MCP 的模式修改、串码原子拒绝、1K 报价不消费、生成去重、全部权限的硬预算和配音暂停；2 个生成只复制本地合成夹具。中文窗口实看「请求批准 / 全部权限」菜单，排版无截断。其他未运行的 GUI 项不算已通过。

## 教训 / 防回归

授权模式只决定是否询问，不决定默认质量，也不解除预算。设置变更必须在第一次写入之前确认；不能靠代理一句“用户同意了”取消权限变更的工具确认流程。项目放行不可跨账号或跨规格/价格上限。长期约束见 [统一设置](../architecture/workbench-and-settings.md) 与 [Sky Studio 任务](../architecture/sky-studio-jobs.md)。
