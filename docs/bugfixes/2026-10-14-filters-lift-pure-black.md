# 2026-10-14 滤镜把纯黑抬成灰：空档、黑场、黑底字卡盖了褪色胶片发灰带色块

> 来源：2026-10-06 审美盲测（[剪辑美感方案](../plans/2026-10-05-editing-aesthetics.md)）。长期约束写进了
> [滤镜](../architecture/filters.md)「纯黑不抬」一节。

## 症状

AI 给整条片子铺一段褪色胶片（`fadedFilm`，风格卡里「怀旧 / 胶片感」那一款），片子里的黑跟着变了：

- 段与段之间的**空档**、转场里**压黑**的那一截不再是黑，是一层偏品红的灰（约 31 / 28 / 30）；
- **黑底字卡**（黑底白字的片头、章节卡）整块发灰，暗处还看得见压缩的色块。

褪色胶片本来就「把黑抬成灰」，画面里这样没问题；问题是空档、黑场、字卡的黑是**内容**，不是画面里的暗部，用户和 AI 都没想让它变。
用户 2026-10-14 拍板：滤镜照旧给画面抬黑褪色，但原本就是纯黑的地方保持纯黑，预览和成片一起改。

## 根因

一款滤镜是一张 33³ 的表，由配方（lift / gain → gamma → 饱和 → 对比）在格点上取值，预览和导出查同一张表。配方对每个输入一视同仁：
褪色胶片的 lift 是 0.055 / 0.04 / 0.05、对比 0.85（以 0.5 为轴），纯黑 (0, 0, 0) 进去出来是 (0.120, 0.109, 0.117)。
空档在两条管线里都是合成的黑底（预览垫黑底、导出补黑场），滤镜盖在合成之后，于是一起被抬。

色块来自同一处：黑底素材编码后不是一片 0，是 0 上下一两个码值的噪声和块边，被抬到 0.12 附近的一块平灰里、再带上一点品红，
压缩时成了看得见的色块。

在黑处往亮里调的不止褪色胶片：雾蓝（0.08–0.10）、灰纪（0.077）、暖阳（0.04）、冷白（蓝 0.01）同样把空档抬成灰。

## 修复

`FilterLUT.apply` 拆成配方本身 `grade` 和一步 `holdingBlack`（表照旧是 `apply` 在格点上的取值，预览和成片自动一致）：

- 输入最亮的那个通道低于 `FilterLUT.blackHold`（4 格 = 0.125）时，配方往亮里调的那部分按 smoothstep 收回来：0 处一点不剩、
  到 0.125 全给。只看最亮的通道，暗而饱和的颜色不算黑。
- 每个通道取「配方」和「收回来的」里暗的那个：往暗里调的（冷铁、夜金、墨影压死黑）一点不碰。
- smoothstep 在 0 处斜率为零：黑底上那一两个码值的噪声不放大，色块跟着没了；保护范围里最陡一格（1/32）升约 0.067，不出台阶。

规矩按「输入是不是黑」定，十款一起，不单改褪色胶片 —— 同一个症状在灰纪、雾蓝上一样。

顺带把 `checks/Filters/main.swift`（基线 602 行）里逐像素那一组拆进 `Parity.swift`，真跑生产导出的那段抽成 `exportTimeline` 两组共用。

## 验证

- `scripts/check-filters.sh` 第四组（`checks/Filters/PureBlack.swift`）：
  - 十款的纯黑那一格（满强度、一半强度）都是 0；出了保护范围和配方一样；保护范围里在配方和原色之间；冷铁 / 夜金 / 墨影暗处照样压死黑；
    褪色胶片把暗灰 0.2 照旧抬到 0.26 以上；从黑往上每一格最多升 0.08。
  - 预览那条路：纯黑交给 `CIColorCubeWithColorSpace`，十款出来都 ≤ 1/255；褪色胶片把 51 灰抬到 61 以上。
  - 成片那条路：黑底素材 0–1 秒、空档 1–2 秒、暗灰素材 2–3 秒，褪色胶片盖满，真跑生产导出：黑底和空档 ≤ 2/255，暗灰照表抬起来（±4/255）。
- 修之前的值（本机按配方算）：纯黑出 褪色胶片 0.120 / 0.109 / 0.117、雾蓝 0.081 / 0.089 / 0.104、灰纪 0.077、暖阳 0.040 / 0.033 / 0.019。
- 反向验证：见 PR 描述（不合并的草稿 PR，CI 上跑）。
- 自动化够不着的：看真片子里黑场渐变的最后几帧（画面先暗到抬起来的灰、最后 0.125 那一截滑进纯黑）顺不顺 —— 写进了
  [滤镜](../architecture/filters.md)的人工回归。

## 教训 / 防回归

- **调色作用于画面，不作用于「没有画面」**：空档、黑场、黑底字卡的黑是编辑出来的内容；滤镜盖在合成之后时，要想清楚合成补出来的那些像素算不算画面。
- **按输入的特征定规矩，不按哪一款**：只改褪色胶片会把同一个毛病留在灰纪、雾蓝里。
- **保护区要连续**：只把正好是 0 的那一格按回黑、旁边照旧抬，暗处的渐变就断成色带 —— 自检里钉了「从黑往上没有台阶」。
