# 2026-10-15 联动把字幕当一整块挪：剪掉的句子留下、开头跑到片段之前、删停顿后两句叠在一起

## 症状

用户转来另一个 AI 会话的反馈（联动开着）：

- 用 `cut_speech keep` 剪 30 秒版，「上网搜索最新信息」「支持的视频时长……」两行字幕说的话都被剪掉了，字幕却被带进了成片 ——
  它们只和保留的片段重叠几帧；
- 之后用 `edit_clip` 改入点（ripple），字幕的位移不一致，有一行的开始时间跑到了片段开始之前。

按代码推下来还有报告没提到的一处：`remove_pauses` / 口头禅 / 重复词在一句字幕的中间或尾巴上切一刀时，这句原样不动、下一句往前挪，
两句会同时出现在画面上零点几秒；切口之后的逐词高亮也和声音错开。

## 根因

联动（[联动](../architecture/timeline-linkage.md)，2026-10-02）把一句字幕和一段音效、一行文字一样当成**一整块**：

1. 底下**还剩一帧**画面就整句保留（规矩 2 / 3：画面全没了才删）；
2. 挪多少按「最早还在的那一截画面」算，**时长不变**；
3. 裁切让画面没了的，留在原地（规矩 4）。

可字幕本来就比说话长：说完多停半秒，和下一句空不到半秒就直接延到下一句前 2 帧（`SubtitleCueTiming`），句子之间几乎不留空。于是：

- 剪掉的那句，显示时间的尾巴蹭进保留段几帧 → 有「还剩的画面」→ 整句留下，按那几帧对齐整句挪过去，挂到前一段上（第一段的就夹在 0）；
- 保留的那句，开头被剪掉几帧（字幕的开口是故意往前估的，见 [cut_speech 只信转写](2026-10-14-cut-speech-trusts-word-times.md)）→
  按剩下那截对齐整句挪，开头挂到片段开始之前；改入点同理，被裁掉那截上的字幕又按规矩 4 原地不动 —— 一部分跟着走、一部分不动，就是「位移不一致」；
- 删停顿时剪掉的正是一句的尾巴（它的停留时间），最早还在的那截位移是 0，这句原样不动、时长不变，下一句却往前挪了一个停顿的长度。

规矩是 2026-10-02 按「一段音乐、一行文字」想的：它们是摆上去的东西，整体挪、保持时长是对的；字幕是说出来的话，跟的是**说话的那几秒**。

## 修复

用户 2026-10-14 拍板（「按你的建议来」）：字幕句另立一条规矩（联动规矩 12，`Sources/SrtFlow/VideoEditTimelineCueFollow.swift` 的 `LinkageCueFollow`）。

- **两头各自跟着画面换算**：只是剪掉 / 裁掉了底下的一部分、或者变了速（剩下的几截前后顺序不变、中间没插进别的东西）时，开头和结尾分别换算 ——
  中间剪掉一截就缩短，开头 / 结尾被剪就收到剩下的那截，变速跟着伸缩；逐词高亮的词时间一起换算（剪掉的词收到切口上）。
- **说话的那几秒剩不到一半**：真删（⌫、`delete_items`、`cut_speech`）就删；不是真删（裁切、变速）就留在原地（同规矩 4）。按**说话的那几秒**算：
  有逐词时间按词，译文按它翻自的那句原文，都没有才按显示时间 —— 按显示时间算的话，删停顿剪掉的正是「多停的半秒」，「OK.」这种短句会被误删。
- 别的情况（换了位置、中间插进了别的、底下没有画面）照老规矩整句挪。
- 「同 id 优先」的账细了一步：同 id 的那段盖住的部分只认它，**它没盖住的部分再找这次新出来的同素材段** —— 一句字幕跨过 cut_speech 剪掉的一截时，
  后面那半在新 id 的碎片上，以前被整个忽略。
- 配音的字幕（规矩 11，`CaptionSourceFollow`）用同一份：变速时长跟着变、开头被裁掉的收到声音开始的地方。
- 写进字幕轨走新的 `SubtitleTrackEditing.setTimings`（开头、结尾、词一起换，译文记「时间改过」，同 `setStarts`）。
- 给 AI 的结果（`AILinkageReport`）：`linkage` 里多两样 —— `shortened_subtitles`（底下有画面被剪掉、收短了的：字里可能还留着剪掉的词）、
  `left_subtitles`（说的话大半被裁掉、留在原地的：用 delete_items 删）。cut_speech / delete_items 的说明和 cut_speech 的 `next_step` 写了这条。
- 长期约束改在 [联动](../architecture/timeline-linkage.md) 规矩 12 和场景表；[方案](../plans/2026-10-02-timeline-linkage.md) 补了这次的板。

## 教训 / 防回归

- **一条规则管好几种东西时，先问每一种「跟着走」跟的是什么。** 音乐、文字是摆上去的，整体挪、保持时长；字幕是说出来的话，跟的是那几秒声音 ——
  同一份「画面账」，落到字幕上要按两头算。
- **判「还剩多少」要量对东西。** 字幕的显示时间比说话长出一截停留，按显示时间判，最常被剪掉的恰好是那截停留，结论就反了。
