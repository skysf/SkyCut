# 2026-11-05 官网演示停在封面且视频轨道像一张宽图

## 症状

用户指出三个交互里的视频应该真正播放，视频轨道却是一张被放大裁切的海报，
看起来不像剪辑软件的连续帧。点选流程步骤后，演示还会静止。

## 根因

1. HTML 视频设为 `preload="none"`，播放适配器在 `readyState < 1` 时直接返回。
   它等素材先加载才调 `play()`，但没有主动加载，浏览器可以始终停在封面。
2. 创建演示在前四个阶段明确禁止播放，点步骤又把 `paused` 设成 `true`。
   完成后的媒体位置还被钉在末帧，进一步放大“只是图片”的观感。
3. 播放头用独立 RAF 流程时钟模拟，视频每偏离 0.3 秒就被重新 seek。时间码推进
   不能证明视频解码器在播放，加载或切后台后还可能反复跳转。
4. 轨道复用了素材库的单张海报，再用整个片段的宽度显示，未提取视频中的连续帧。
5. 旧验证用 `readyState:1` 的假视频跳过了浏览器真实的未加载路径；界面验收看到
   时间码变化就当成播放正常，没有钉住自然播放、完成状态与步骤定位的行为。

## 修复

- `showcase-media.js`：进入视口后设置 `preload=auto` 并显式 `load()`，静音内联循环；
  加载完成后才启动单个播放请求。只有用户定位、重播、720p / 1080p 换源会 seek，
  平常由解码器自然播放。换源保留实际播放位置，自动播放被拒绝时允许点击重试。
- `showcases.js`：流程阶段与媒体时钟分别管理，画面字幕、播放头、时间码取实际的
  `video.currentTime`；滚出视口和切后台仍会暂停。完成后的预览继续循环。
- `showcase-controls.js`：选择步骤后定位并继续播放；播放条也能暂停和继续。
  剧本、角色和生成进度变成局部浮层，保留正在播放的画面。
- `build-showcase-filmstrips.mjs` 从每段本地演示抽取 12 个不同时间点，生成三张
  1920 × 90 JPEG 图集。`showcase-filmstrip.mjs` 按每格 `viewBox` 展示真实连续帧，
  `preserveAspectRatio` 保持画面比例；轨道不增加任何视频解码器。

## 验证

- `website/tests/showcase-playback.test.mjs` 覆盖首次可见时主动加载、三个演示立即
  播放、自然播放不重复 seek、播放头取解码时间、完成后循环、离屏暂停、自动播放
  被拦后的重试、增强换源保留位置、点击步骤继续播放与连续帧轨道的生产接线。
- 反向验证：临时还原旧 `showcase-media.js` 与 `showcases.js`，针对播放与步骤的
  两条守卫都变红，报 `preload none ... actively loaded` 和控制器未接入；恢复修复
  后新回归检查全部通过。
- 本地 Safari 已观察到创作画面从企鹅人物切到破冰船并继续推进，完成状态也循环；
  画质演示的实际画面、播放时间和播放头推进，轨道显示 12 个不同表情与姿态的帧。
  字幕演示显示人物真实口型，法语字幕与 00:07 的画面、播放头对应。
  不以模拟计时器变动代替画面验证。32 项网站测试通过，本地生产构建通过。

## 教训 / 防回归

浏览器未加载的视频不能靠等待 metadata 自己开始；必须覆盖真实的 `readyState=0`
路径。时间码只能证明它的时钟在走，视频播放必须看解码器时间与实际画面。
长期约束和人工回归清单见 [SkyCut 官网](../architecture/skycut-website.md)。
