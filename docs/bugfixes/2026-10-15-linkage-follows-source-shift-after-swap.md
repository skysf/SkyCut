# 2026-10-15 upscale 换源 / 换文件之后，压在那段上的字幕、文字、音效全被挪了一个偏移

## 症状

做「裁切让字幕说的话剩不到一半就删」（联动规矩 12 的改法，同一天的下一个 PR）之前，交接里点出一个风险：
upscale 换源（`VideoEditProject+Upscale.swift` 的 `applyUpscale`）和 `edit_clip` 换文件（`ClipFileReplacement`）都是同一个 id 换了素材、
源时间整体平移，联动的账（`TimelineLinkage.Ledger`）认同 id 的段时不看素材、按源时间对账，压在上面的东西可能被挪错。先写了一条自检
（`checks/TimelineSnap/LinkageSwap.swift`，第 1i 组）看现状，果然：

- 主轨一段用原片的 5–15 秒，upscale 文件是原片的 4–16 秒（带 1 秒余料）：换源之后入点 5 → 1，压在这段上的字幕、文字、音效、形状、
  滤镜、B-roll **全被挪了 4 秒**（字幕 [2,4) → [6,8)），联动报「挪了 6 样」。
- `edit_clip` 把这段换成另一个文件、从它的第 3 秒起：同样全挪了 2 秒；换文件的同时把段挪到后面，压在上面的东西挪的量比段多 2 秒。
- 配音段（规矩 11）换成另一个声音文件、从它的第 2 秒起：它的字幕被报成「留在原地」（`left_subtitles`），只是位置碰巧没变。

联动 2026-10-02 上线、upscale 换源 2026-10-02 做完，这个毛病从那天起就在：谁在联动开着时点过「替换」，段上的字幕和文字就错位了
一个余料的长度。用户没报过 —— 盲测和实测里 upscale 过的段上面没压东西。

## 根因

联动规矩 1「跟着画面走、不跟 id」：每样东西看自己底下压着哪个素材的第几秒，改之后去找同 id 的段（`Ledger.afterByID`）或新出来的
同素材段，按**源时间**求交、换算回时间线。换源 = 源时间整体平移（[四之五](../architecture/video-edit-project-file.md)：新文件的 0 秒
不是原片的 0 秒），同 id 的段改之后入点变了、素材也变了，账却还按「同一条源时间轴」算：原片第 7 秒在新文件里是第 3 秒，账把它
当成「这一帧挪到了新文件第 7 秒所在的时间线位置」，于是整体挪一个偏移。配音那条（`CaptionSourceFollow`）同样把换了文件的段原样当
幸存者，交集为空就成了「留在原地」。

## 修复

- `TimelineLinkage.Piece.rebased(onto:)`：同 id 的段换了素材（`asset` 变了）时按「这段现在摆的地方，画面就是改之前这段的画面」记账 ——
  素材和入点都按改之前的，只有时间线上的位置、长度、速度是现在的。`Ledger.init` 建 `afterByID` 时对每个同 id 的段做一次；
  `CaptionSourceFollow.plan` 的幸存者和退路同样用它。素材没换的段原样。
- 这条写进 [联动](../architecture/timeline-linkage.md) 规矩 1 和场景表；[四之五](../architecture/video-edit-project-file.md) 补一句。

## 验证

- `scripts/check-timeline-snap.sh` 第 1i 组（`checks/TimelineSnap/LinkageSwap.swift`）：upscale 换源（偏移 4）之后联动报空、九样东西原地
  （字幕的开头、结尾、词的时间都不变）；换成另一个文件同样；换文件同时把段挪到后面，压在上面的东西正好跟着挪 10（不是 12）、配乐不动；
  配音段换了声音文件，它的字幕不动、不报。修之前这 11 条正是症状里的数字（挪了 6 样、字幕 [6,8)、挪 12、字幕报成留在原地）。
- 第 1f / 1g / 1h 组全部照旧绿（658 项）。
- 反向验证（不合并的草稿 PR，CI）：见文末。

## 教训 / 防回归

- **按源时间认画面，换了文件源时间轴就换了。** 同 id 换素材是时间线上「位置没变、画面当没变」的操作（换源、换文件都只改读哪个
  文件、从第几秒读），账要按改之前的素材和入点记；以后再加「换素材」类的操作（换回原片、重链接到别的文件）都走 `rebased`。
- **动一条规矩之前，先把它旁边的地雷用自检踩一遍。** 「裁切让字幕删掉」要是直接改成「parts 为空就删」，upscale 一次段上的字幕就全没了 ——
  交接里写的风险，先写自检再动手，当天就省掉一轮返工。
