# 2026-11-11 森林色的提示外面套着一圈直角方框

## 症状

用户 2026-11-11 上午报「系统深色时提示是黑底黑字」的两张截图里还有一处：提示块外面套着一圈细的**直角**方框 ——
系统深色时是浅色的一圈，系统浅色时是灰的一圈。深底深字是另一个原因，由
[系统深色时按钮提示是深底深字](2026-11-11-tooltip-dark-on-dark-in-forest-theme.md)（#388）修了；这一圈方框 #388 修完还在：
系统深色 + 森林色时变成浅色气泡外面一圈暖白的直角，系统浅色时照旧是一圈灰的直角。

只有森林色（默认主题）有，经典色的提示一直是圆角的。

## 根因

- **提示的根铺了一整块矩形的主题底色。** 提示的根是 `TooltipContent(...).appLanguage()`；`appLanguage()` 组合了主题修饰器
  `AppThemeModifier`，它给每个呈现根铺 `.background(palette.window)` —— 森林色是整块矩形的暖白 `#F3F0E8`，经典色是
  `.clear`。这是给窗口、sheet 铺底色用的；提示的宿主也是呈现根，于是圆角气泡后面也铺了一整块矩形。
- **提示面板的形状全由内容决定。** 面板无边框、透明（`backgroundColor = .clear`、`isOpaque = false`），窗口服务器按内容
  不透明的地方定窗口的形状，再按这个形状画影子和外描边。铺了矩形底色之后：圆角气泡外面的四个直角露出暖白，影子 / 描边
  也贴着矩形走。系统浅色：浅灰气泡 + 暖白直角 + 贴着矩形的灰影子，就是「灰的一圈」；系统深色（#388 之前）：深色气泡 +
  暖白直角 + 深色外观给窗口描的一圈边，就是「浅色的一圈」。
- **不是影子没刷新。** 怀疑过「复用同一个面板，换了内容没 `invalidateShadow()`，影子还是旧的形状」。探针里先弹长的再弹
  短的（中间收起、不收起两种，鼠标从按钮 A 直接划到 B 走的是不收起那条）、先短后长，按窗口号带影子拍：影子每次都跟着
  当前的内容（短的 106×70 pt、长的 283×70 pt，经典色每次都是圆角的影子）。所以没有加 `invalidateShadow()`。
- #388 的案例把深色那一圈写成「深色外观下窗口服务器给面板画的阴影和描边」：描边确实有，但它是**直角**的，是因为窗口本身
  被铺成了矩形；暖白的直角和这一圈描边都来自主题的底色，#388 改了面板的外观之后还在（见下表中间一列）。
- **为什么上线时没发现**：只有森林色铺底色；直角只露在 6 pt 圆角外面那一小块，影子贴着矩形也只差几个像素；提示只在鼠标
  停住时才出现，主题上线时的人工清单只看了窗口。

## 修复

- `Sources/SrtFlow/InstantTooltip.swift`：气泡的形状只留一份 `TooltipContent.bubble`（`RoundedRectangle(cornerRadius: 6)`），
  气泡的底、描边都用它；`show` 里宿主的根在 `.appLanguage()` **外面** `.clipShape(TooltipContent.bubble)`。主题的底色还在，
  只是被裁在气泡里面（材质盖着，看不见）：四个角透明，窗口服务器的影子 / 描边跟着圆角走。
- 裁切必须在 `.appLanguage()` 外面。裁在里面（`TooltipContent(...).clipShape(...).appLanguage()`），主题的底色在裁切之后才铺，
  照样是整块矩形（反向验证见下）。
- 主题修饰器不改：窗口、sheet、popover 要的就是铺满的底色。透明、形状由内容决定的自建面板只有提示这一个，规矩写进长期约束。

## 教训 / 防回归

- **呈现根的 `appLanguage()` 会铺主题的窗口底色，森林色是整块矩形。** 透明、形状由内容决定的自建面板（提示），根要在
  `.appLanguage()` 外面裁成自己的形状，不然直角露在外面、窗口服务器也按矩形算影子 / 描边。长期约束写进
  [即时提示](../architecture/instant-tooltips.md)第五节第 7 条和 [界面主题](../architecture/app-themes.md)「AppKit 自建的窗口」。
- **一张截图里的每处异样都要对上原因再结案。** 深底深字和直角方框在同一张截图里、原因不同；修完一个，要用同一个场景再拍
  一张，看另一个还在不在。
- **按窗口号拍（`screencapture -l`，不加 `-o`）看得到影子和描边**，要起探针的终端有录屏权限、窗口在屏幕上（挪到屏幕外拍不到，
  放到所有窗口后面就行）；离屏渲染（`cacheDisplay`）看不到影子，但看得到四角透不透明，自检用后者。
