# 2026-11-11 官网的小字：手机上小于 12 px、演示区对比度不够、标题跳级、字体换上后首屏挪 1 px

SEO / GEO 那一轮审计（C16）和首屏 3D 的浏览器检查各撞出几条，都是「看得见但读不清 / 读屏器读不顺」。
一起修，一起配守卫。

## 症状

1. **手机上有小于 12 px 的字。** 390 宽的首页上 31 类文字不到 12 px：首屏底部三个标签 9 px、
   系统要求那一行 11 px，演示区的对话窗 9–11 px、编辑器示意窗口里的时间码 / 轨道名 / 标尺 / 片段名 / 字幕条
   5–8 px，定价对比表 10–11 px，平台卡片、登记表单的说明、页脚 11 px。文档、隐私、文章页的页脚同样。
2. **演示区的小字对比度不到 4.5:1。** 「交互演示」标签 4.25、对话窗的连接状态 3.88、步骤说明 4.40、
   还没轮到的步骤 2.28（整行 42% 不透明）、播完后的「已完成」1.49（脚本把它调到 35%）、阶段按钮 3.24、
   标尺 2.96、检查器的小字 3.2–3.6、片段名 2.58、译文字幕条 3.56、声音轨的名字 2.75–4.42、画质角标 3.39。
   定价和平台卡片上的灰字在浅绿底上 4.04–4.35，差一点。
3. **桌面档标题从 h2 直接跳到 h4。** 每个演示的 h2 后面跟着四个 h4：「素材库」「转场」「检查器」「输出」。
   手机上素材栏和检查器是收起来的，所以只有桌面档跳。
4. **网页字体换上之后整个首屏往下挪 1.25 px。** 桌面 1440，WebKit 里最明显：加载完成后才换字体，
   首屏的 3D 场景和左边的文案一起动一下。

顺带露出来的三条老毛病（改字号时量出来的，改之前就有）：手机上步骤说明被裁掉半行（每个演示 3–5 处），
「剧本」「角色」两个浮层在手机上超出预览框；演示一开始播，对话窗先矮一两行、1.8 秒里再长回来
（英文第一个演示 338 → 300 → 316 → 338）。

## 根因

1. 演示区的编辑器窗口是照 App 画的示意图，桌面上按比例缩小，字自然小；手机那一档只是接着往下缩
   （`font-size:5px`），没有人问过「这个字在手机上还读不读得了」。其余几处是各自为了挤进一行调的。
2. 灰绿色的小字是一处一个颜色凭眼睛挑的（`#697566`、`#72806a`、`#758169`、`#809074`…），没有对着它
   所在的底色算过；「暗下去表示还没轮到 / 已经结束」用的是整行降不透明度，把字也一起降了。
3. 示意窗口里的面板标题写成了 `<h4>`。它们是图里的标签，不是页面的章节，本来就不该进标题大纲。
4. `.hero-badges` 没写行高，`line-height:normal` 取字体自己的度量：回退字体下这一行 20 px，Outfit 下 15 px。
   首屏是网格、3D 场景在上面那一行里竖直居中，下面矮 5 px、上面那一行就高一点、场景挪 1.25 px。
5. （对话窗先矮后高）用户那句话是「把气泡的文字换成前 N 个字」打出来的，两三行的话从一行起步；
   桌面上气泡有两行的最小高度所以看不出，手机上没有。

## 修复

1. 手机档（≤ 600 px）**看得见的字一律不小于 12 px**。读的字直接调大（首屏标签、系统要求、对话窗、
   阶段按钮、语言按钮、定价对比表、平台卡片、表单说明、页脚；示意窗口里的标题、时间码、工具栏、轨道名、
   标尺、画质角标、三个浮层）。放不下 12 px 的不显示：片段名、字幕条里的字（字幕条的字包进
   `.show-cue-text`，手机上隐藏，条还在；预览画面上那句字幕照旧）、标尺隔一个显示一个。
   为了放得下：示意窗口在手机上略高（1.15 → 1.05）、轨道名那一列 11% → 15%；画质角标挪到左上，
   「剧本」浮层改成贴底通栏、出现时角标让位，「角色」浮层加宽 —— 浮层不再出框。
   步骤说明固定三行高、超出用省略号，播完后那一行占同样的高度：对话窗从第一步到结束、四种语言、
   三种手机宽度下都是一个高度（之前英文会跳 12 px）。
2. 演示区的灰绿小字统一成 `--show-quiet`（`#5a6652`），在它用到的每种底色上都 ≥ 4.5:1。
   还没轮到的步骤从 42% 提到 72%（过 4.5:1，状态靠前面的圆圈区分）；`showcase-view.js` 不再把「已完成」
   调暗，只让三个点停住。片段名加一条深色底、声音轨的名字加深色小标签、译文字幕条和画质角标的底加深。
   全站的 `--muted` 从 `#676d62` 调到 `#5d6358`（浅绿底上 4.96:1），「需要 Pro」同步。
3. 面板标题改成 `<p class="show-panel-title">`，样式不变。
4. `.hero-badges` 写死 `line-height:1.25`（12 px 字正好还是 Outfit 下的 15 px，桌面版面不变）。
5. 打字时气泡里一直放着整句话：打出来的在前一个 `span`，还没打到的在 `.show-untyped`（`visibility:hidden`、
   `aria-hidden`）里照样占位，气泡从第一个字起就是最终的大小。页面的 HTML 不变（两个 `span` 是脚本建的）。

页面的 HTML 变了（标题、字幕条的标记），`npm run stamp:pages` 把四个首页记为当天。

## 教训 / 防回归

- **缩小的示意图里的字，到手机上要么放大到读得了、要么不显示。** 5 px 的字不是「小一点」，是噪音。
- 小字的颜色从一个量过的变量来，别一处挑一个；「暗下去」别用整行的不透明度，字会跟着掉到读不清。
- 图里的标签不是标题。标题层级是给读屏器和搜索引擎看的页面大纲。
- 行高别留 `normal`：那是字体的事，字体一换高度就变。
- 逐步出现的文字先占好最终的位置再显示；检查「高度不变」要在变化进行的那段时间里连着量，
  只量几个静止的时刻，过不过看时机 —— 一项时过时不过的检查，先当成它量到了真东西去查。
- 长期约束在 [SkyCut 官网](../architecture/skycut-website.md)「小字读得清」。
