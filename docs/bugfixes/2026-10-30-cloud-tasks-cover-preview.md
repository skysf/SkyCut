# 2026-10-30 多个生成任务横幅挤占预览

## 症状

四个视频同时排队时，每项都在预览上方画整条黄色横幅，重复阶段标签挤满编辑器，画面预览被压缩。

## 根因

任务清单直接挂在 AI 横幅下面，任务数量决定预览额外占用的高度；没有统一入口或积分汇总。
生成失败结束后立即移除，upscale 的停止又先删除清单项，用户难以继续看到取消竞态或未知扣费。

## 修复

按用户选择改为右上角「生成任务 N」入口与锚定浮层，内部滚动。每项保留名字、模型、阶段、报价、可取消阶段的取消按钮；总价只加进行中的已知报价。
AI 的撤销横幅独立保留。失败 / 未知扣费提示保留到用户关闭，upscale 取消不先删除状态；计时只在打开的浮层里运行。
把录屏按钮与帧率菜单拆成各自的小视图，编辑器根文件降到 600 行以内，不再订阅录屏全局状态。

## 验证

- `scripts/check-all.sh` 全部 75 组通过；89 项云端媒体检查通过；1,027 条界面文案在 en / es / zh-Hans 全覆盖，完整 App 编译通过。
- 反向验证：临时恢复没有工具栏任务入口的旧编辑器，接线守卫变红；临时按「请求已发出」把正常取消误留为警示，取消守卫变红；两份修复恢复后均转绿。
- 免费真实 App / MCP / 窗口：四项排队合计 640；关闭 / 重开不取消；取消一项后变 3 项、400 积分且无警示。本机账只退一次；409 已开始的保留结局，后续查到服务端完成，取消请求没有重复。
- 六项任务内部滚动到底，长名中间截断且不挤积分 / 按钮；980pt 窗口（900pt 编辑器加侧栏）仍能打开浮层。英 / 中 / 西文显示与语言切换通过，AI 的撤销这一轮保留。
- 超时提示持续可见，逐项关闭后入口与浮层自动收起。验证使用回环假服务与假 Key，没有付费提供方调用；测试身份随后清理。
