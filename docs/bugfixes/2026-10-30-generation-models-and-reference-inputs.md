# 2026-10-30 生成接口固定首个模型且缺少多参考素材

## 症状

Sky Studio 有多个图片 / 视频模型，SkyCut MCP 却只能按目录第一条生成，参数固定为 H3 的 480p / 768p，只接受一张首帧。
AI 无法查询每个模型能收多少图片、视频、音频；Seedance 真人参考拒绝被转成通用失败，不能安全地自动切换。

## 根因

服务端 SkyCut 适配器只有两模型白名单；客户端也取第一模型、用静态枚举和默认值，协议中没有多模态引用。
失败解析只留下错误句子，并假设 failed 就已退款；提交结果未知时单凭没拿到任务号退本机账，也不能证明没有扣费。

## 修复

- Sky Studio PR #228（main `bfc5860e`）开放两个图片 / 六个视频模型、有序参考与首尾帧，复用网页提供方；能力从共享合同投影，实际探测后再次核对价格上限。
- MCP 可只读查询完整模型目录；生成可点名模型，按亚洲 / 其他与明确最高质量的偏好挑兼容模型，从目录读取时长、分辨率、画幅和参考限制。
- 全部输入先过文件授权，测量 / 验证后报价；上传顺序、输入身份和消费确认绑定，替换复用上传，不丢素材、不缩短输出。
- 保留结构化拒绝和真实退款字段。只在 Seedance 真人参考已退 / 未扣时自动替换一次，最高消费不超原批准价；退款晚到只查原单；未知结果保留幂等 key 和账。
- 同步修正 upscale / 配音对无证据退款的判断；未知失败不能标成已退款。

## 验证

- 服务端：133 项相关合同回归通过、生产构建和所需 CI 通过；生产受控发布与上线后的冒烟通过，线上部署与 `bfc5860e` 一致。
- 客户端：完整 App 编译通过；732 项 Sky Studio 检查通过；2,664 项 MCP 检查通过。
- 免费实际 App / MCP：目录查询、图片主题默认、有序图 / 视频 / 音频上传、尾帧、提交 / 查询拒绝后替换、退款晚到、替换价格上限、未知结果不重生成全部通过，成品实际解码通过、上传 / 下载不带 Key。
- 反向验证：临时恢复目录首个模型并撤去替换的退款条件，732 项里 **5 项失败**；两份修复均自动恢复。
- `scripts/check-all.sh` 全部 75 组通过，推前 `scripts/check-guards.sh` 通过；配音 / 声音克隆的实际 App 冒烟也通过。

## 教训 / 防回归

接口开放包括模型能力、参考类型和限制，不能只换模型名字。明确的业务拒绝与实际退款是两个独立事实，未知结果绝不能靠再次收费生成解决。
长期合同与人工回归见 [Sky Studio 的任务](../architecture/sky-studio-jobs.md)第四、八节。
