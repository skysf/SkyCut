# 2026-11-01 旁白云端已生成，本地分句失败后只能人工找回

## 症状

克隆旁白分批生成，第二批已经返回完整音频，但本地分句 / 字幕对齐失败，整个任务报错。调用方只能人工找回成功音频，辨认哪些段落还没生成，再单独补生成；重发整稿可能重复付费，重新入轨也可能叠出两份内容。

## 根因

`SkyStudioVoiceoverRun.execute` 把云端生成、下载、分句和最终入轨串成一个临时流程。只在 catch 时尽力移动当前 `activeRaw`，defer 删除其余临时文件；`SkyStudioVoiceRender` 的段落对应、跨批长句采样和剩余计数只存在内存。保留一个完整文件没有保留可执行的处理进度，也没有 MCP 恢复入口或入轨去重回执。云端成功被后续本地错误盖成了整项失败。

## 修复

- 复用 `SkyStudioVoicePlan`、`SkyStudioJobRun`、`SkyStudioVoiceAudio`、`SkyStudioVoiceSplit`、`AIVoiceoverTool.plan/apply` 和原字幕实现，不另造生成 / 切句 / 入轨管线。
- `SkyStudioVoiceCheckpoint` / `SkyStudioVoiceRecovery` 把输入、原工程与落点、每批原文和句索引、幂等 key / 原单、原成品地址、完整音频、分析、完成文件和稳定入轨身份持久写在配音目录。提交前写 submitted；云端成功在本地处理前保存；每句完成即记进度。统一执行器可等待原单身份的 checkpoint，进度不再异步晚写覆盖恢复结果。
- 明确区分云端生成、本地分句、字幕对齐，另报下载、落盘和入轨阶段。成功生成的批次永不因后续失败变回 missing；未知提交只能 GET 原单，无号保留 key 待核查。
- 继续用 `add_voiceover` 起任务、`get_job` 查进度：`{resume: <recovery_file>}` 默认不付费，只处理已有结果；`{resume: <recovery_file>, generate_missing: true}` 才补生成明确未成功的批次。混传原稿 / 音色拒绝；同一文件同时恢复复用正在跑的任务。
- 已完成句子不重写，长句按原批次顺序重建；最后一次撤销同时入轨音频与字幕。先保存稳定片段 UUID，提交成功保存回执；重复恢复、最后回执未写成、用户之后撤销，均不能自动插第二份。
- `get_job` 返回完成、待本地恢复、未生成、未知部分，以及各批原文映射、保存文件与可执行的恢复参数。已保存工程重开后仍能显式恢复；没有原单号的未知请求不自动 POST 查找。

- `scripts/check-voice-recovery.sh` 链接实际 App 的目标文件，使用独立测试 bundle、假 HTTP、合成 WAV，只注入转写结果；实际执行解码、`SkyStudioVoiceSplit`、AAC 落盘、MCP 恢复入口、字幕、工程与 UndoManager。第二批空转写失败时已提交 2 批；默认本地恢复后仍是 2 批，只补第三批后为 3 批；最终 6 段音频 / 6 条字幕、一次撤销 / 重做、重复恢复不变。
- 同一检查覆盖云端部分失败且明确退款、跨批长句字幕对齐失败、原文件不重写、硬预算为 0 仍能本地恢复、缺失部分生成遵守硬预算、取消与未知结果不重放、最终回执写入前退出的去重窗口。
- `scripts/check-sky-studio.sh` 共 866 项通过；`VoiceRecoveryChecks` 真写读恢复记录，核对映射 / 原 key / 成品元数据 / 原播放头 / 600 权限、坏记录拒绝、已知原单只 GET，以及本机退档完成后不再误报待生成。
- `scripts/check-mcp.sh` 共 2,846 项通过，检查恢复参数接入、未知参数仍拒绝、目录与协议和原有编辑行为；`scripts/check-guards.sh` 全部通过，检查模块、文档索引及生产接线。
- 反向验证：临时撤掉“成功批次不算 missing”与本机原音频优先复用，真实回归出现 12 项失败，明确包含第二批被重复提交、补生成 / 预算不再只算第三批；临时撤掉入轨前稳定 UUID 的记录，回执缺失窗口 / 一步撤销等 4 项断言失败。两份生产源码最终按原字节恢复，再跑正向回归。没有用真实 Key 或用户钱包做测试。

## 教训 / 防回归

云端成功是一项不可被本地失败抹掉的事实。付费生成与本地分句 / 字幕处理应有分别的状态、持久进度和恢复入口；“留了一个文件”不足以支持可重复、不会重复付费的恢复。去重还要覆盖“工程已经改好、最终回执尚未写成”的窗口。长期合同与人工抽查边界见 [Sky Studio 的任务](../architecture/sky-studio-jobs.md)第五节与第七节。
