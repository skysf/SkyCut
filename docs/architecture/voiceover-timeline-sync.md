# 按旁白段落同步时间线

`sync_voiceover` 首版只处理调用方明确给出的段落映射，不推测画面的语义，也不生成声音。
先用 `add_voiceover` / `add_clips` 得到新音频段，再从 `get_timeline` / `get_subtitles` 取身份。
本地对齐是长任务，立即返回 `job_id`，用 `get_job` / `cancel_job` 查询和取消。

## 映射合同

```json
{
  "language": "zh",
  "paragraphs": [{
    "from": 0,
    "to": 10,
    "voiceover_id": "c3",
    "old_voiceover_id": "c2",
    "clips": [{"clip_id": "c1", "fit": "speed"}],
    "texts": ["t1"],
    "shapes": ["s1"],
    "subtitles": ["l1", "l2"]
  }]
}
```

- 每次 1–100 段，只作用在 `project` 指定的工程。旧范围 `from` / `to` 必须连续、有序；新第一段默认从首段 `from` 开始，
  可用根层 `start` 指定。后面的新起点只由前面的实际音频长度累加，不逐段取整，不留累计误差。
- 新旁白必须是已入轨、可听、速度为 1 的纯音频段。未裁的旁白实测完整文件时长；裁过的只取明确选中的素材窗口。
  时间探测复用 `MediaProbeCache.measuredAudioDuration`，绕过旧缓存，不用单次 PCM 读取返回的帧数代替媒体总长。
- `old_voiceover_id` 可选，在同一次事务里移除该段旧音频；不删文件。省略的对象保持原样，不靠 linkage 猜着带上。
  要顺延后续段落，必须一起映射；未映射的尾段造成冲突时整次拒绝。
- 每个身份只能出现一次，映射的对象必须完全在所属旧段落里；跨段的先分割。显式链接的伙伴不能悄悄漏掉，需先解除链接或映射替换。
- 画面 / 文字 / 形状两头按自己在旧段落中的相对位置换算。轨道、文字行、形状数组顺序和样式、取景、可见性不重排。
  文字 / 形状低于现有工具的 0.2 秒下限直接拒绝，不能让单项工具悄悄夹紧导致越过段落边界。

## 画面适配

- `speed` 默认：保留素材窗口，调用 `AIClipEditPlan` → `AIClipEdit` 调整速度。算出低于 0.1 或高于 8 就拒绝，不夹成边界值。
- `trim`：保留速度，调用同一素材窗口编辑规则；长音频可用现有尾端余料，超出实际素材就拒绝。图片按现有静帧视频上限处理。
- `freeze`：短音频沿用裁切；长音频保留原运动段，末尾补一段现成的图片段，单次补 0.1–60 秒。
  直接复用手动定格的 `extractFrame` / `writeFreezeImage`、`StillImageClipFactory` 和 `EditClip.makeFreezeClip`；
  不写抽帧 / 合成第二实现。隐藏、占位、正在定格、主轨叠化中的取帧点或引擎不可用均拒绝。
  取景 / 关键帧在末帧烘成静态样式，出场效果与转场留在尾帧，原运动段只保留入场。
  失败 / 取消 / 过期丢弃本次新 PNG，成功保留用于重做；原音频始终不删。

## 字幕保持原稿

字幕调用既有 `SkyStudioVoiceAudio` 本机转写服务，从新文件取得词时间。按每条字幕轨分别把新词映回原稿，
`SubtitleCueWords.realigned` / `matchingCharacterCount` 共用字符对齐；仅比较键可折叠繁简体，存储文字与 UTF-16 位置仍指原稿。
每句至少 90% 的字母 / 数字匹配，词时间单调且不能越过实际音频窗口；词跨在两条字幕中间、对不全或语言不符就整次失败。
不按旧字幕时长伸缩，也不用 ASR 的简体 / 纠错文字覆盖原稿。

用 `SubtitleTrackEditing.setTimings` 写两头和新的相对词时间；原文 cue 的来源改指新声音。cue 的 id、文字、隐藏状态、语言、
工程字幕样式与布局保持，译文轨照既有合同独立。翻译稿不能直接对齐另一个语言的声音；需要它自己的匹配语音。
每段最多 2,000 原稿字符 / 4,000 转写字符，超限先拆映射，避免字符动态规划占用无界内存。

## 唯一批量提交与校验

`AIVoiceoverSyncInput` 全验映射；`AIVoiceoverSyncPlan` 持有现有 `AIBatchEdit`，在副本上调用单项规则。
相邻段一起变长时，中间状态会临时压住后段：只在这条完整计划里延迟片段重叠检查，普通 `edit_clip` / `edit_clips` 仍逐项检查。
全部普通参数与对齐成功之后才准备定格素材，最后再查同轨片段 / 同行文字 / 同轨字幕的完整冲突；不通过自动抬轨来改叠放关系。
形状沿用模型允许相互覆盖的规则，V1 转场沿用既有有效重叠上限。

所有 await 之后以及提交前都检查原工程代号、完整时间线快照、无手势进行中；准备期间用户编辑、工程切换或关闭均整次拒绝。
最终只调用一次 `AIBatchEditTools.commit`：复用 `AIBatchEdit.commit` 的过期拒绝和唯一 `AIUndoGrouping.step`，
`alreadySettled: true` 选择已有 `restoreTimeline` / `adopt` 路径原样采用完整候选时间线，**不再次磁吸 / 联动**，全局开关也不改。
一次登记、一次预览请求；完成后按已有长任务合同记录这一轮并为未存工程保存。`get_job` 返回各段旧范围、新范围及应用结果。
任何本地失败只需保留已有声音并重试同步入口，不调用付费生成。

## 回归

`scripts/check-voiceover-sync.sh` 链接实际 App 对象，以合成 WAV / 视频验证短、长旁白、V1/V2/文字/形状/字幕、
真实末帧抽取 / 静帧转码、过期拒绝、最终冲突及整个工程一步撤销 / 重做；仅 ASR 词时间注入，不访问生产 Key 或云端。
接入 `check-all` 第 1 组。MCP 参数发现与未知字段在 `check-mcp` 验；生产复用接线由扫描守卫钉住。

人工回归（发版前）：

- 真实克隆的短 / 长旁白各同步一次，播放段落接缝，核对字幕开口、末字、繁体原稿和逐词高亮。
- 有上下层取景、文字 / 形状入出场、末尾定格的工程，核对预览和成片的接缝与层序；⌘Z 一步回到原工程，⌘⇧Z 一步恢复。
- Linkage / Magnet 开着和关着各试一次，未映射的配乐 / 形状原地，映射对象不二次位移；另一工程窗口无变化。
