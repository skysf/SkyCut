# 声音怎么过一刀（set_transition 的 sound）

> 已生效的长期约束（2026-11-16 起）。来由：用户测南极预告片时点名两处镜头之间的原声一刀硬换（保温箱 → 地铁、公交金属声 → 高架），
> 接顺 24 个接点时每一刀都是手工叠轨、手画渐变；以后「切点上声音硬跳」会被检查报出来，得有**一步就能修**的办法（生产反馈 MCP-32）。
> 用户 2026-11-16：「我们只是在测试 skycut，发现缺失的，更好的东西就想办法补充进去」。
> 代码：`CutSoundRequest`（词表、默认帧数、参数）、`CutSoundCut`（哪一刀、两边的声音在哪、哪一层）、`CutSoundPlanner` / `CutSoundLevelPlan`
> （怎么改，纯值）、`CutSoundEdges`（挪一头、分离、让路）、`CutSoundLimits`（最多几帧、量电平的窗）、`CutSoundReport`（结果）、
> `CutSoundMeasure` / `AICutSoundTool`（App：量电平、找拍子、提交）。说明书：`MCPGuideCutSound`。
> 相关：[联动](timeline-linkage.md)（规矩 13）、[声音：音量与渐入渐出](audio-fades.md)、[音量曲线](audio-volume-curve.md)、
> [主轨转场](transition-handles.md)、[AI 接口（MCP）](ai-control-mcp.md)第四节第 61 条、[MCP 编辑参数合同](mcp-edit-parameters.md)。

## 一、一句话

AI 点名一刀（画面换了的地方），选一种过法、给帧数，一次调用 = 一步撤销，**画面一帧不动、只动声音**。做不到（余料不够、会伸过隔壁镜头）
就整个不做，照实回「最多 N 帧」和为什么。

## 二、几种过法（`CutSoundMode`，词表 `MCPVocabulary.cutSounds`）

| sound | 改哪一边 | 落成什么 | 不给 frames 时 |
| --- | --- | --- | --- |
| `crossfade` 叠着换 | 两边 | 上一个的声音拖过切点 N 帧、下一个的提前 N 帧；两边都在整段 2N 帧里渐变（交叉） | 0.25 秒 |
| `lead` 先进（J） | 下一个 | 提前 N 帧开始、在这 N 帧里淡进来；上一个的声音不动 | 0.667 秒 |
| `lag` 拖后（L） | 上一个 | 拖过切点 N 帧、在这 N 帧里淡掉；下一个的声音不动 | 0.875 秒 |
| `bed` 垫一层底 | 底那一段 + 两边的电平 | 音频轨上的一段声音伸到切点两边各 N 帧；两边的原声比底响 6 dB 以上的整段压到「底 + 6 dB」 | 2 秒 |
| `on_beat` 落在拍子上硬换 | 两边 | 一刀切，切口挪到 ±N 帧里最近的一拍（取整到帧），报挪了几帧 | ±0.333 秒 |
| `gain` 调增益 | 下一个 | 整段平移：给了 gain_db 照它，没给就调到和上一个切点前的电平一样 | — |
| `cut` 回到一刀切 | 两边 | 两边的声音都正好断在画面的切点上，没有渐变 | — |

默认帧数按工程帧率换算（24 帧 / 秒：6、16、21、48、8）。出处：真人剪的南极正片 45 刀实测 —— 下一场的声音先进 21 次、中位 16 帧，上一场的
拖过 18 次、中位 21 帧（都是 24 帧 / 秒）；「从下面穿过去」= 两边都待 2 秒以上；音乐重音在 ±8 帧以内算跟上（预览板检查的口径）。
gain_db 也能跟着 crossfade / lead / on_beat / cut（加在下一个的声音上）和 lag（加在上一个的声音上）一起给：一次做完「地铁的声提前 12 帧淡进来、
压 6 dB」。

## 三、规矩（只能这样做）

1. **画面一帧不动。** 不改任何画面段的位置、长度、转场：V1 的排布不变，磁吸不排（`MainMagnet` 只在改到 V1 排布时排）、联动不挪别的东西。
   画面上已有的转场留着（只管画面）。和 `type`（画面转场）不在同一次调用里：一起给就整个不做，叫 AI 分两次。
2. **要挪的那一边，声音先分出去。** 画面自己带着的声音（V1、上层轨都算）要离开画面的边，先走界面上「分离音频」那一份规则
   （`ClipSoundSeparation.separate`：画面静音、声音到音频轨、链接组、音量 / 曲线 / 渐变 / 场景跟着走），不另写一份。**分出去之后另一头照它此刻
   实际响的样子**（`CutSoundEdges.renderedSound`，和音频引擎同一份账：V1 先展开转场借余料、定格那截没声音，有转场的一头按转场叠的时长渐变）——
   不然分一刀的声音会让隔壁那刀的转场交叉淡变变成硬断。只动这一种过法点名的那一边（lead 只动下一个、lag 只动上一个），另一边原样。
   已经分出去的声音（同组、同文件、换算对得上的那段）直接改它。`gain`、`bed` 不挪声音的边，不分离。
3. **给绝对值。** 每种过法把它管的那一头设成「切点 ± N 帧」，不是在上一次的基础上再加；再调一次同一刀就是改成新的样子，`cut` 回到一刀切。
   挪一头时源时间跟着换算（「源 ↔ 时间线」不变）：挂在声音上的字幕、音量曲线、标记都不动。
4. **不悄悄改小。** 要的帧数超过最紧的那条上限就整个不做（几刀一起时一刀做不到就全不做），回 `invalid_parameter`（parameter = frames、
   requested、allowed.maximum、能做到就给 suggested、reason 写哪条卡住了）。上限：声音的文件在切点那一边还剩多少（余料）、
   声音不伸过隔壁那个镜头（lead / crossfade 不早于上一个镜头的开头、lag / crossfade 不晚于下一个镜头的结尾）、bed 的那段文件够不够伸、
   不早于时间线的开头。
5. **挪过的声音撞上同一条轨上的别的段就让开**：另找一条放得下的音频轨、都放不下新开一条（`TimelineLinkageLanding.settle`，同联动 / 拖文件的梯子）。
   叠着换的两段因此一个在 A1、一个在 A2；一串刀叠下来是棋盘似的两条轨。
6. **渐变用引擎现有的**（线性斜坡，[声音：音量与渐入渐出](audio-fades.md)第 4 条）：两段不同的声音叠着换，正中会塌下去约 3 dB。改成等功率是另一个产品决定。
7. **一次调用 = 一步撤销**（路由包 `AIUndoGrouping.step`，先 await 量完再同步提交；中途时间线变了就不落、叫 AI 重来）。`all=true` 是 V1 上每一刀，
   一刀缺这种过法要的声音（静音、图片）就跳过、在结果里列出来（`skipped_no_sound`）；别的原因做不到照第 4 条整个不做。
8. **电平怎么量**（`gain`、`bed`）：切点前 [−0.32, −0.02) 秒、切点后 [+0.02, +0.32) 秒（躲开切点上那一帧左右），底在切点两边各 0.3 秒 ——
   同真人片和预览板的量法。听到的电平 = 文件在窗里的均方（画波形那一份 `WaveformStore`，不另起读采样的循环）+ 段的音量线在窗中点的 dB +
   所在轨的推子。**不算渐变**：调的是镜头本身的电平，渐变是过切点那一下的事。波形还没读到那里就等（最多 20 秒），等不到回 `media_loading`
   （retryable）。
9. **垫底拿哪段、多长、压多少**：layer_id 给了用它（必须是音频轨上的声音、不是两边自己的）；没给就是音频轨上和「切点 ± N 帧」重叠最多的那段
   （一样多取长的：整段配乐，不是切点上的一下音效）。伸到切点两边各 N 帧（默认 2 秒），不够就照第 4 条。电平按真人的规矩：一层底在切点上
   **不比较响的一边低 6 dB 以上**才盖得住跳变（真人片里没东西盖着的刀两边最多差 3.4 dB，盖住的差 6–40 dB），所以比「底 + 6 dB」还响的那一边
   整段压到「底 + 6 dB」；**只压不抬**（不替用户把镜头的声音推响）。底在切点上是静的就不压、结果里说一句。
10. **落在拍子上**：拍子来自 `AIBeats`（listen 的 beats、cut_to_beat 同一份分析），换到时间线、只留那段音乐放着的那几拍；拍子不清楚
    （可信度低于 `AudioBeatTracker.clearConfidence`）不踩，同 cut_to_beat。窗里挪不过去的拍子（余料不够、会把一边裁没）跳过、取下一个近的；
    一样近取往后的。正好落在切点上（0 帧）而且画面带着声音、没有转场时不分离，只把那一刀的渐变清掉。
11. **调增益**：默认挪下一个镜头的声音去对上一个（一刀一刀往后对，已经对好的不再动）；给了 gain_db 照它。整段平移，有音量曲线就整条平移
    （同 `edit_clip volume_db`）；顶到音量上下限被夹住，结果里 `gain_db` 是实际的、`requested_gain_db` 是要的。
12. **联动**：分出去的声音跟着它自己的画面走（[联动](timeline-linkage.md)规矩 13）—— J / L 切伸到隔壁镜头底下的声音，磁吸重排、裁隔壁、删第一个镜头
    之后照样和画面对得上（[案例](../bugfixes/2026-11-16-separated-sound-left-behind-on-magnet-repack.md)）。

## 四、给 AI 的那一面

- 参数（`set_transition`）：`sound`、`frames`（0–600）、`gain_db`、`layer_id`；刀用 `after_clip_id`（切点前那一段画面，V1 或上层轨；也可以给它分出去的声音）
  或 `all=true`（V1 每一刀）。名片只写一句，长话在说明书 `skycut_guide topic=set_transition` 的 sound / sound_rules / sound_results 三节
  （清单离 10 万字的上限只剩约 1.5k 字，没开新工具：sound 和画面转场都是「怎么过一刀」，`set_transition` 本来就收 after_clip_id / all）。
- 结果（`CutSoundReport`，按提交之后的工程读）：每一刀 `out` / `in`（放声音的那段 id、轨道、断在 / 开始于哪一刻、`offset_frames` 离画面切点几帧、
  `fade_frames`、刚分出来的 `separated_from`、`gain_db` / `requested_gain_db`）、`room_frames`（两边文件在切点那一边还剩几帧：还能放多宽）、
  on_beat 的 `beat`（at、moved_frames、music）、bed 的 `bed`（id、track、from、to、extended_frames）和 `levels_db`；`picture: unchanged`。

## 五、守卫

- `scripts/check-mcp.sh`：`checks/MCP/CutSoundChecks.swift` / `CutSoundLevelChecks.swift` —— 每种过法的时间、渐变、轨道、增益逐项断言；场景含余料不够
  （整个不做、报最多几帧、做不到时不给建议数）、两边是同一素材（叠出来的两段同一刻读文件的同一秒）、切点在转场上（声音分出去、画面转场留着）、
  另一头有转场（分出去之后照样借尾料、按转场渐出）、磁吸开着（切点在叠的正中、V1 不动、再排一次不变）、联动开着（这一步不挪别的；之后删掉第一个镜头，
  J 切的声音裁头、对得上）、上层轨的刀、给分出去的声音当 after_clip_id、几刀一起（棋盘两条轨、缺声音的跳过、一刀做不到全不做）、参数核对、
  词表对账、默认帧数、结果的样子；说明书三节只提真有的名字（`GuideChecks`）。
- `scripts/check-timeline-snap.sh` 第 1j 组：联动规矩 13（见联动那一篇）。
- 路由：`checks/MCP/router-wiring.sh` 钉着 `AICutSoundTool.apply` 包在 `AIUndoGrouping.step` 里。
- **反向验证**（2026-11-16）：一次撤掉六处，各自的检查都红（共 17 项）—— 上限不拦（余料 / 隔壁镜头 / bed 的文件）、分离时不照实际响的样子
  （另一头的转场）、切点不取叠的正中（磁吸）、bed 不压、on_beat 不跳过挪不过去的拍子、all=true 不跳过缺声音的刀；恢复后全绿。

## 六、人工回归（要耳朵和真窗口，发版前过一遍）

- 两段不同地方的环境声，叠着换 6 帧：听不到一刀硬换；正中那一下塌得不明显。⌘Z 一步回去，声音回到画面里（分出去的轨收掉）。
- 先进 16 帧：下一场的声音在切点前淡进来、画面照旧在切点上换；拖后 21 帧同理。
- 有配乐的工程 bed：配乐被伸长盖住切点，响的那一边压低了几 dB（结果里的 levels_db 对得上听感）。
- on_beat：声音换的那一下落在音乐的重拍上，画面没动。
- 时间线上看：分出去的声音在 A1 / A2 交替，和画面链接着；拖画面声音跟着走；磁吸开着把前一个镜头拖到最后，后面镜头的 J 切声音还贴着自己的画面。

## 七、已知不足

- 线性渐变，叠着换的正中约 −3 dB（见第三节第 6 条）。
- lead 的那几帧一直在淡入：对白要「提前进来、一开口就是满的」时，lead 之后对分出来的声音 `edit_clip fade_in 0`。
- bed 只压不抬：底太轻时它只说一句，不替用户把底推响（用 `edit_clip volume_curve` 在切点附近抬）。
- 只认画面的切点：音频轨上两段声音之间的接缝（两段环境声首尾相接）不收，照旧用 edit_clip 的 start / source_in / fade_in。
- 界面上没有入口（这次只给 AI）。
