# 联动：压在主轨块上的东西跟着它的画面走

> 2026-10-02 起。用户要「和剪映一样：打开之后，只要和主轨上的块在一个范围内的，任何东西都链接在一起，删除一起删、移动一起移」，
> 细节由我按用户体验拍（[方案](../plans/2026-10-02-timeline-linkage.md) 记着每条怎么定的、为什么）。本文是长期约束：
> 规矩、落在哪、守卫、人工回归。代码：`Sources/SrtFlow/VideoEditTimelineLinkage.swift`（规则）、
> `VideoEditTimelineCueFollow.swift`（字幕句两头各自换算，规矩 12）、`VideoEditTimelineCaptionSource.swift`（规矩 11）、
> `VideoEditTimelineLinkageLanding.swift`（撞上了往哪让）、`VideoEditProject.perform` / `liveApply`（钩子）、
> `VideoEditProject+Selection.swift`（拖动计划要的名单）。
> 相关：[拖动手势](timeline-drag-gestures.md)、[剪辑页上记住的开关](editor-remembered-toggles.md)、[AI 接口（MCP）](ai-control-mcp.md)。

## 一、一句话

**「联动」开关（工具栏那个链子，`EditorToggles.linkage`，默认开）开着时：时间线上任何不在主轨上的东西，跟着它底下压着的主轨
画面走 —— 画面挪到哪它挪到哪，画面被删了它也删。** 显式的链接组（视频 + 分离出来的音频、录屏画面 + 麦克风，`linkGroup`）照旧，
而且更强（拉开了也跟）。单向：主轨带别的，别的不带主轨。

## 二、规矩（`TimelineLinkage`）

| # | 规矩 | 代码 |
| --- | --- | --- |
| 1 | **跟着画面走，不跟块的 id。** 每样东西看自己底下压着主轨的哪些画面（哪个素材的第几秒）；一次改动之后那些画面挪到哪，它就挪到哪。分割、`cut_speech`、定格插入切出来的新 id 照样认（同一个素材、接着的源时间）；**同 id 的段永远优先**（粘贴 / 复制出来的同素材新段不算画面挪过去了；重链接换了路径也不算）。**同 id 的段换了素材**（upscale 换源、`edit_clip` 换文件：只换读哪个文件、从它的第几秒读，时间线上的位置和长度不动）按「这段现在摆的地方，画面就是改之前这段的画面」记账 —— 新文件的 0 秒不是原片的 0 秒，按新入点对账会把压在上面的东西挪一个余料的长度（2026-10-15，[案例](../bugfixes/2026-10-15-linkage-follows-source-shift-after-swap.md)） | `Ledger`：改之前每段主轨的「时间线 ↔ 源时间」账，改之后按同 id、再按新出来的同素材段找画面去了哪；同 id 换了素材的经 `Piece.rebased(onto:)` 按改之前的素材和入点记（规矩 11 的 `CaptionSourceFollow` 同样） |
| 2 | **完全落在一段主轨块里的**：删它就删、挪它就挪。挪多少按它底下**最早还在**的那一截画面算，和那截画面的相对位置不变（字幕句另见 12） | `Ledger.outcome`：`inside` |
| 3 | **跨两段的**（配乐铺整片、一行文字跨过接缝）：底下的画面**全部**挪同一个量才跟，否则不动；画面**全没了**才删（字幕句另见 12） | `Ledger.outcome`：非 `inside` 时所有幸存画面的位移一致才 `.move` |
| 4 | **真删才连带删。** ⌫、AI 的 `delete_items` / `cut_speech` 传 `deletesContent: true`；裁切、变速、定格、拖动、AI 的 edit_clip 让画面没了的，东西**留在原地不动**（裁切是边拖边看的探索动作，拖过去一句字幕就没了太吓人；留在原地一眼能看见、按 ⌫ 就删） | `perform(deletesContent:)`；`liveApply` 永远 false |
| 5 | **这次操作自己碰过的东西不再碰**（值和改之前不一样就算碰过）：拖动的成员已经按实际落点平过了、链接组的伙伴已经一起裁了，别再按联动挪一次 | `follow` 只看 `before == after` 的那些 |
| 6 | **撞上了让开**，让的永远是这次挪过的那个：上层轨的段往上抬一轨、音频轨的段另找一条，都放不下新开一条（同拖文件 / 粘贴的梯子；隐藏的轨不上梯子）；文字往上找空行、滤镜往上找空层；字幕句和形状允许重叠 | `TimelineLinkageLanding.settle` |
| 7 | **一处收口。** 规则只在 `TimelineLinkage.follow`，钩在 `perform` / `liveApply` 收尾（磁吸合拢之后、补色之前）：删、拖、裁、变速、加转场、定格、粘贴插进主轨、拖文件插进主轨、AI 的 ripple、磁吸拨开合拢，全都自动对；不存任何状态、不抬工程格式 | 守卫 `checks/timeline-drag-wiring/linkage.sh` |
| 8 | **拖动中**：被拖的主轨块压着的东西是这一轮拖动的成员（`TimelineLinkage.attachments`：底下压着的主轨块全在要动的名单里才算），实时跟着画、**没有障碍**（不许反过来挡住主轨块）、不当吸附参考点；磁吸下按宿主实际落到哪再平一次（`ClipDragPlan.Member.host` → `realignCompanions`）。别的主轨块合拢是松手时的事，它们压着的东西也松手时跟 | `VideoEditProject.linkedAttachments` / `ClipDragPlan.adding(attachments:)` |
| 9 | **哪些算「任何东西」**：上层视频轨、音频轨（含分离出来的音频）、文字、形状（含盖一块）、滤镜段、字幕句（原文 / 译文两条轨各按自己的时间判）。标尺标记不算（它钉在时间线的绝对时刻）；段上的标记、转场、关键帧本来就长在段上 | `follow` 里五类各扫一遍 |
| 10 | **开关关着**：以上一样都不发生，只有显式的链接组（老行为） | `perform` / `liveApply` / `linkedAttachments` 都先看 `linkageEnabled` |
| 11 | **生成的字幕句跟着它的那段声音走**（2026-10-14）：原文字幕记着是从哪一段生成的（`CueMeta.provenance.clipID`，转写和配音都记），那段**不在主轨上**（配音、音频轨上的采访、上层轨）时，段挪了 / 裁了头 / 变了速，字幕按它在素材里的那一刻跟着挪（裁头时那一刻没动就不挪）；段被真删字幕一起删（规矩 4）。来源在主轨上的照旧只跟画面（规矩 1），两条不叠；这次碰过的不碰（规矩 5）；译文轨没有来源、不跟（两条轨独立）。这是联动里唯一按 id 认的一条：字幕本来就是那段声音说出来的（[案例](../bugfixes/2026-10-14-voiceover-subtitles-stay-behind.md)） | `CaptionSourceFollow`，`follow` 收尾时调（主轨画面没变也调） |
| 12 | **字幕句不整句平移，两头各自跟着画面换算**（2026-10-15）：一句字幕（原文、译文两条轨；规矩 11 的配音字幕也是）底下的画面只是被剪掉 / 裁掉了一部分、或者变了速（剩下的几截前后顺序不变、中间没插进别的）时，开头和结尾**分别**换算 —— 中间剪掉一截就缩短，开头 / 结尾被剪就收到剩下的那截，变速跟着伸缩，逐词高亮的词时间一起换算。**说话的那几秒剩不到一半**：真删就删，不是真删就留在原地（规矩 4）、报给 AI。「说话的那几秒」有逐词时间按词、译文按它翻自的那句原文、都没有才按显示时间（显示时间里有说完多停的半秒，删停顿剪掉的正是它）。换了位置、中间插进了别的，照规矩 2 / 3 整句挪。账也细了一步：同 id 的段没盖住的那部分，再找这次新出来的同素材段（跨过 cut_speech 剪掉那截的字幕，后半在新 id 的碎片上）（[案例](../bugfixes/2026-10-15-linkage-moves-subtitles-as-a-block.md)） | `LinkageCueFollow`（`VideoEditTimelineCueFollow.swift`），`followMain` 和 `CaptionSourceFollow` 都用它；写进轨道走 `SubtitleTrackEditing.setTimings` |

### 几个具体场景（也是自检的用例）

| 场景 | 结果 |
| --- | --- |
| 磁吸开，删主轨第 2 段，它上面有两句字幕、一段音效 | 两句字幕和音效一起删；第 3 段起的主轨块前移，它们上面的字幕 / 文字 / 音效跟着前移同样多 |
| 一句字幕跨过第 1、2 段的接缝，删第 1 段 | 说的话大半在第 2 段上：收到第 2 段上那一截（跟着前移，从 0 起）；大半在第 1 段上：跟着删（规矩 12） |
| 配乐从 0 铺到尾，删中间一段 / 把第 1 段拖到最后 | 配乐不动、不删 |
| 配乐从 0 铺到尾，删第 1 段 | 后面全部前移同样多 → 配乐跟着（夹在 0），不删 |
| 磁吸开，拖第 3 段到第 1 段前面 | 第 3 段上的字幕实时跟着去前面；第 1、2 段后移，它们上面的东西松手时跟着后移 |
| `cut_speech` 剪掉一段里的三处停顿 | 停顿上的东西删掉，停顿之后的字幕 / 文字跟着画面前移；一句字幕的尾巴压在停顿上的，跟着剪短（不和下一句叠） |
| `cut_speech` 只留几句（30 秒版） | 剪掉的句子删掉（字幕的尾巴蹭进保留段几帧也删：说的话一个字都没留）；保留的句子收到各自那截上，开头不早于那截 |
| 磁吸开，裁掉第 1 段的头 2 秒 | 第 1 段里的字幕跟着画面前移 2 秒；跨在裁切点上的那句收到段的开头；被裁掉那 2 秒上的字幕（和说的话大半被裁掉的）留在原地（不删），AI 的结果里列出来 |
| 变速 2 倍 | 段里的东西各自跟着自己那一帧到一半处（时长不变；字幕的时长也减半） |
| 定格插入 | 定格点之后的字幕 / 文字跟着后移一个定格时长（联动关着时照旧「定格只动它所在的那一条轨」） |
| 分割一段、改转场类型、改音量 | 画面没挪，什么都不动 |
| 主轨块拖去上层轨 | 它还在（同 id），压在它上面的东西按它的新位置跟；它原来的邻居合拢，邻居上的东西跟着 |
| upscale 换源（点「替换」）、`edit_clip` 换文件 | 什么都不动、不删：压在这段上的字幕（开头、结尾、词的时间）、文字、音效、形状、滤镜、B-roll 原地；换文件的同时挪了段，它们跟着段挪、相对位置不变；配音段换了声音文件，它的字幕不动 |

## 三、给 AI 的那一面

- `get_timeline` 的结果带 `linkage: true/false`；`delete_items` / `cut_speech` / `edit_clip` / `cut_to_beat` 的结果里带
  `linkage: {moved, deleted, note}`（什么都没动就不带，`AILinkageReport`）；字幕收短了的列在 `shortened_subtitles`（字里可能还留着剪掉的词，
  叫 AI 用 get_subtitles 看）、说的话大半被裁掉留在原地的列在 `left_subtitles`（叫 AI 用 delete_items 删）—— 只有留在原地的也报。
- 工具说明：`delete_items`、`freeze_frame`（`MCPTimelineTools.swift`）、`cut_speech`（`MCPSmartEditTools.swift`）写明开关开着时别的轨跟着动；
  `cut_speech` 的 `next_step` 按开关分两种说法（关着才提醒重新生成字幕）。
- AI 的工具按用户的开关走，和手动一个口径；`cut_speech` 剪掉的那几块永远是真删（`deletesContent: true`），它本来就不管开关带着链接的声音剪。

## 四、已知不足

- 跨段的东西只按「全部画面挪同一个量」判：一句字幕跨过接缝、前一段被拖去别处时，它留在原地（没有正确答案）。
- 裁切 / 变速让画面没了的东西留在原地（规矩 4），一眼看得见但要自己删。
- 变速只挪起点、不缩时长：段里 2 秒的文字、音效在 2 倍速下还是 2 秒（字幕句 2026-10-15 起两头换算、时长跟着变，规矩 12）。
- 字幕剪掉一截之后字没变：收短的那句里可能还留着被剪掉的词（AI 的结果里列出来）；没有逐词时间、也没有来源的字幕（导入的、手打的）
  只能按显示时间判剩多少，删停顿时短句可能被误删。
- 拖动中只有被拖那块压着的东西实时跟；邻居合拢带动的要松手才跟（和主轨块自己的表现一致）。
- 「联动设置」按类型勾选（剪映有）不做；要的时候再加。
- 规矩 11 按来源段的 id 认：配音段被分割之后，右半段那几句字幕记的还是左半段，挪右半段它们不跟（挪左半段才跟）。

## 六、人工回归（改这些代码后过一遍）

- 开关开着、磁吸开着：拖一段带字幕和音效的主轨块到别的位置 —— 字幕和音效实时跟着块走，松手后邻居合拢、邻居上的字幕跟着归位；⌘Z 一步全回。
- 删一段主轨：它上面的字幕 / 文字 / 音效没了，后面的全部前移、字幕仍贴着说的话；配乐不动。
- 裁一段主轨的头：拖把手时段里的字幕实时前移；被裁掉那一截上的字幕留在原地。
- `cut_speech` 剪停顿之后字幕仍贴着说的话（`get_job` / 结果里有 `linkage`），一句的尾巴被剪掉时不和下一句同时出现在画面上。
- `cut_speech keep` 只留几句：被剪掉的句子的字幕一行都不剩；保留的句子的字幕从它那截画面的第一帧起，不在前一截上提前出来。
- 改一段主轨的入点（AI 的 edit_clip ripple 或手拖把手）：跨在裁切点上的那句从段的开头起；被裁掉那截上的字幕留在原地，AI 的结果里有 `left_subtitles`。
- 开关关着：以上一样都不跟（只有分离出来的音频跟视频）。
- 磁吸关着、开关开着：删一段留着缝，只删它上面的东西，后面不动。
- 开关开着：给一段压着字幕和文字的主轨块做 upscale、点「替换」（或让 AI `edit_clip file=` 换成另一个文件）—— 字幕和文字原地不动；⌘Z 一步撤回。
